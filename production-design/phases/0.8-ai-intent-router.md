# Blink 0.8 — 意图路由优化 + AI 能力基础

&gt; **范围**:无 AI 路由优化 + AI Provider 抽象 + 基础 AI 插件
&gt;
&gt; **原则**:本体保持轻量，复杂 AI 能力放插件，本地模型按需下载，不强制捆绑。

---

## 一、0.8.0：无 AI 路由优化（优先做）

先做不需要 AI 也能提升体验的路由优化，低风险、高收益。

### 1.1 模糊匹配 + 编辑距离容错

**问题**：
- 「设 置」（中间有空格）搜不到
- 「设置一下」搜不到
- 「設置」（繁体）搜不到
- 打错一个字（「设值」）搜不到

**方案**：
- 关键字匹配前先归一化（去空格、转小写、繁转简）
- 编辑距离 ≤ 1（短词）视为匹配
- 匹配度按距离加权（完全匹配 = 1.0，差一个字 = 0.8）

**实现量**：小，只改 `RuleRouter` 匹配逻辑。

---

### 1.2 多语言关键字支持

**问题**：英文系统用户输入 `settings` 搜不到设置。

**方案**：
- 每个 trigger 支持多语言关键字数组
- 按系统语言自动适配，支持手动切换

```json
"triggers": [
  {
    "type": "keyword",
    "keywords": {
      "zh": ["设置", "配置"],
      "en": ["settings", "config", "preferences"]
    },
    "surface": "priority"
  }
]
```

**实现量**：小，manifest 解析 + 匹配逻辑扩展。

---

### 1.3 Context 感知路由（无 AI）

**问题**：复制了代码后还得手动输入「翻译」。

**方案**：
- 简单规则引擎，根据 Context 状态调整插件优先级
- 纯规则，不涉及 AI 推理

| Context 状态 | 路由调整 |
|---|---|
| 前台是 VS Code + 剪贴板是代码 | 「解释代码」「格式化」插件置顶 |
| 前台是浏览器 + URL 是 GitHub | 「打开仓库」「搜 Issue」插件置顶 |
| 剪贴板是 `http://` | 「打开链接」「下载」动作置顶 |
| 剪贴板是文件路径 | 「打开目录」「在资源管理器定位」置顶 |

**实现量**：中，`RuleRouter` 接入 `ContextSnapshot` + 规则配置。

## 二、AI 能力基础（0.8.1+，后置）

> **核心原则**：AI 逻辑不放本体，全部做成可插拔插件。本体只提供最小 Provider 抽象。

### 2.1 最小 AI Provider Trait

**本体只定义接口**，具体实现由插件提供。避免膨胀 core。

```rust
// 仅定义在 plugin 模块，core 不依赖
pub trait AIProvider: Send + Sync {
    fn id(&amp;self) -&gt; &amp;str;
    fn is_available(&amp;self) -&gt; bool;
    
    // 只保留最基础的两个方法
    async fn chat(&amp;self, messages: &amp;[ChatMessage]) -&gt; Result&lt;String&gt;;
    async fn chat_stream(&amp;self, messages: &amp;[ChatMessage]) -&gt; Result&lt;Stream&gt;;
}
```

**不做的事**：
- ❌ 不内置 embedding 推理
- ❌ 不内置本地 LLM
- ❌ 不做复杂的 Provider 管理
- ❌ 不自动下载模型（用户手动触发才下）

---

### 2.2 云端 AI 插件（OpenAI 兼容）

**作为独立插件实现**：
- 一套代码支持 OpenAI / 通义千问 / 豆包 / 任何兼容接口
- API Key 加密存储（Windows Credential Manager）
- 流式响应 + 打字机效果

**用户体验**：
1. 设置页 → AI Tab → 「添加 AI 提供商」
2. 选择类型 + 输入 API Key + 测试连接
3. 自动注册 AI Provider，`ai xxx` 触发可用

---

### 2.3 本地模型按需下载（预留口子）

**设计原则**：
- 默认不捆绑任何模型（安装包保持小巧）
- 用户主动点击「下载模型」才开始下载
- 下载进度在设置页显示，可暂停、可取消
- 支持自定义本地模型路径（用户自己放模型文件）

**初期只支持**：
- `all-MiniLM-L6-v2`（~20MB，用于 embedding 语义匹配）
- 更复杂的本地 LLM 后续再说

---

## 三、VectorRouter 语义匹配（0.8.2+，可选）

**可选项**，用户启用 AI 后才生效。

- 使用云端 embedding（OpenAI）或本地 embedding（用户下载了模型）
- 内置 50+ 常用意图模板
- 用户历史行为自动学习
- 置信度阈值可调

**不做的事**：
- ❌ 不引入 zvec 等复杂向量数据库
- ❌ 初期内存暴力 cosine 够用（1000 条向量以内）

## 五、验收标准（0.8.0）

```bash
cargo test --bin blink
cargo run

# 模糊匹配
→ 输入「设 置」→ 匹配到打开设置
→ 输入「设置一下」→ 匹配到打开设置
→ 输入「fy hello」→ 匹配到翻译插件

# Context 感知
→ 复制一段英文文本 → 按 Alt → 翻译插件自动置顶
→ 复制一个文件路径 → 按 Alt → 「打开目录」动作置顶
```
