语音输入

按住 Alt+Space 说话，松开后文字自动上屏。云端 STT 需配置供应商，本地 STT 需安装 FunASR 环境。

云端供应商

所有供应商均使用 OpenAI 兼容接口（/v1/audio/transcriptions），仅 Base URL 不同。API Key 独立存储于系统凭据管理器，与大模型密钥互不共享。

云端模式为非流式：按住说话 → 松开后一次性发送整段音频识别。不支持边说边出字预览（云端 API 按音频时长计费，伪流式的重复请求会导致账单膨胀）。

Python 环境

Blink 通过 uv 自动管理独立的 Python 3.12 环境，安装 PyTorch + funasr，无需手动安装 Python 或 pip 包。
