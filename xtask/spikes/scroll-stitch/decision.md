# scroll-stitch spike 结论

日期：2026-09-29。合成电池（10 场景 × 20 帧 × 6 算法，200 对/算法），
确定性种子可复现。**合成数据只能证明方向，绝对数字需真实回放校准。**

## 一、总表

| 算法 | 成功率 | wrong（静默损坏） | rej（安全拒绝） |
|---|---|---|---|
| baseline（生产移植） | 35.0% | **130** | 0 |
| baseline-fix | 34.0% | 132 | 0 |
| robust | 39.5% | 18（全部为 lowdetail 的 unchanged 卡死） | 103 |
| phase | 26.0% | 76 | 72 |
| phase-mask | 26.0% | 76 | 72 |
| hybrid | **46.0%** | 30（18 同 lowdetail） | 78 |

关键读法：**baseline 的失败模式不是"拒绝"，是 65% 静默损坏**（错位拼接
直接产出）。robust/hybrid 把 wrong 从 130 压到 ≈0（可比场景），代价是
安全拒绝——符合生产"定位不确定时拒绝猜测"的铁则。

分场景要点：

- 大重叠（70%/90%）+ 固定层：baseline 12~16 wrong；robust 0 wrong；
  phase 16~20/20 全 exact、亚像素误差 0.00。
- 31% 重叠：baseline 8~9 wrong；robust/hybrid 0~2 wrong，接受率 9~11/20。
- 完全周期列表：baseline 错误接受 16/20（生产中即损坏）；robust 正确拒绝
  20/20；hybrid 拒绝为主。相位相关峰比守门在此场景不可靠（接受垃圾 20/20）。
- 重叠 20%（位移 640 超出 0.78H=624 搜索上限）：全员失败。1D 投影 PC
  理论可达但混叠严重（wrong 9 / rej 11）。

## 二、发现的生产算法问题（stitch.js，可独立成立）

1. **精搜 skip bug（一行可修）**：粗搜网格是 1,5,9,…（≡1 mod 4），但
   精搜 skip 条件写 `distance % 4 === 0 && distance <= coarseDist`，跳过的
   恰是**从未被粗搜测试过**的点。真位移 ≡ 0 (mod 4) 且粗搜最佳落在 +1 时，
   精搜永远测不到真峰 → 永久 ±1 像素。实测修正后 near 38→16、exact 32→52
   （plain-70 场景 ex 0→8 全部精确）。修正：skip 条件改为
   `distance % 4 === 1`（粗搜真正走过的点）。
2. **采样行网格与周期内容锁相（测量混叠）**：24 行均匀采样的行间距
   ≈ usable/24（如 376/24≈15.67px），与周期性内容（16px 行距文本、列表行、
   表格）锁相时，24 个采样行可以**全部落在行间空白上**——此时任意远距位移
   的分数都是纯噪声（≈1.5），甚至低于真值处的噪声（≈1.6），产生 ±3px 宽
   的远距假峰（实测 -136 反向峰击败真值 240）。假接受 → 静默损坏。
   生产真实 UI（文件列表/聊天/表格）周期性极常见。缓解：接受判定采样加密
   （48 行实测消除该类假接受）。
3. **低细节页面 unchanged 卡死**：大片空白时 same_score≈噪声地板（~2.2）
   < 2.5 阈值 → 每帧都判 unchanged → 采集永不前进。需要 informative-aware
   的 unchanged 判定。
4. **反向假接受**：-1 方向候选在稀疏/周期内容上可拿到噪声级分数，
   1.08 方向惩罚不足以压制（实测 baseline 选 -136/-421）。严格方向门控
   或全量验证可挡住。

## 三、算法结论

1. **鲁棒 SAD 管线方向成立**：双侧行变化掩码（比较对 curr 行 y 与 prev 行
   y+shift 两侧都要非固定）+ 截尾均值选候选 + 全量 48 行 SAD 验证 +
   远距多义守门。三个必须遵守的实现细节（都实测翻过车）：
   - 掩码必须**双侧**检查——悬浮按钮经 prev 侧 y+shift 进入比较对；
   - 截尾下限不能放松（行数不足宁可直接 INF，放松后混叠窗口重新刷低分）；
   - 验证采样必须比候选选择更密（24 行的混叠会传染给守门）。
2. **1D 行投影相位相关只能当快路径**：大重叠时完美（exact + 亚像素），
   ≤31% 重叠在准周期投影上系统性混叠（新内容占 69%，周期混叠峰压过真峰）。
   掩码版（phase-mask）与不掩码表现一致——混叠根源是投影本身，不是固定层。
3. **hybrid（PC ∪ SAD 全搜候选 + 鲁棒精修 + 全量验证）综合最好**，且天然
   支撑把搜索范围扩到 >0.78H（PC 候选不受 SAD 上限约束）。
4. **全量验证与鲁棒选择分工**（= 生产"粗召回宽松 + 全分辨率确认严格"
   哲学）：鲁棒分只负责选候选，接受/多义判定回到全量口径——空白行在错误
   位移上依然匹配空白，全量分数在远距位移天然高企，判别力来自未掩码行。
5. **未解决**：≤20% 重叠（需 2D 相位相关 / 特征点 / UIA 位置先验）、
   完全周期内容（正确行为是拒绝 + 先验，纯像素无解）、低细节（需检测并
   提示，而非硬匹配）。

## 四、落地建议（优先级）

- **P0（一行）**：修精搜 skip bug（见二.1）。
- **P0.5（小改）**：unchanged 判定 informative-aware；接受判定采样 24→48 行。
- **P1（管线）**：robust 管线移植回 stitch.js（纯 JS，无新依赖；行变化
  掩码 + 截尾候选 + 全量验证 + 多义守门）。成本：约 2× 基线采样量，
  逐帧 < 数十 ms 级。
- **P2（增强）**：PC 做大重叠快路径与重定位粗召回（亚像素 + 全局候选）；
  ≤20% 重叠与周期内容留给 2D PC / 特征点 / UIA ScrollPattern 位置先验。
- **横切**：先用现有诊断回放（diagnostics.js + replay-runner.mjs）收集
  真实失败 case 建回归集，任何算法改动过同一批回放再上线。
