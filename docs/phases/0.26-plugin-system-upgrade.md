## 二、背景与动机

天气插件原有地点、供应商和配置耦合，IP 信息也未清楚区分本机地址与站点观测出口。本版建立统一服务，并完善文件搜索、剪贴板与截图的高频交互。

**维护澄清**：宿主已有配置注入、HTTP 代理和 Capability 执行链路；插件无需自行读库或直连网络。长图 Pin 已复用预热窗口，超高长图的差异是拖动方式，不能把图片编码/加载等待误判为冷建窗。

## 三、核心设计与维护要点

### 3.1 地点与天气分责

LocationResolver 与 WeatherProvider 经 ResolvedLocation 连接，Query/ToolCall 共用 WeatherService。显式 city/location 优先于默认地点；严格匹配且唯一才自动查询，其余返回 needs_location，候选查询不隐式改默认值。保存原坐标、坐标系与来源身份，供应商仅派生请求参数；彩云区域未知需确认，不猜国界或回写转换坐标。

### 3.2 供应商与结果

Open-Meteo 使用 current/daily 与完整 WMO 映射；和风采用专属 Host/Key、GeoAPI 与天气 v1；彩云采用 v2.6、metric:v2 和同源签名/编码。统一结果保留地点、来源、有效时间、天气代码、warnings 与 attributions；缺失值不补为晴天或零，partial 不混合供应商，复制完整摘要并保留来源时区。

### 3.3 配置、缓存与取消

地点草稿独立提交，普通字段/触发词/密钥操作共享写队列与 revision/CAS；密钥按类型存 CM。配置提交见 [后端 spec §7.6](../specs/spec-backend.md#76-插件配置与密钥提交强制)。地点与天气缓存分别有界，只缓存有效完整结果，配置代次隔离回填；合并请求需覆盖调用期限，等待者独立取消。显式降级默认关闭，共用原预算；取消不承诺撤销已发上游请求，执行契约见 [后端 spec §4.4](../specs/spec-backend.md#44-插件执行契约强制)。

### 3.4 IP 地址与出口

本机地址来自网卡快照，出口来自检测站点；非临时/临时 IPv6 可同时有效，单站点结果不代表所有目标的选路。增强网卡/代理详情与 IPv6 检测默认关闭。IPv4 国内、国际两组独立，IPv6 单组独立；组内主备按序，只接受对应族公网地址。60 秒缓存与来源节流分别约束，失败/取消也不能绕过节流，旧结果不得冒充新请求成功。

### 3.5 主窗口统一列表导航

偏好统一归 app.search.wheel_mode（默认 step），旧字段通过双分片 CAS 事务迁移并移除；配置损坏不覆盖原值。滚轮余量/反向/上下文复位由 list-navigation.js 管理，键盘按既定视口语义执行，热切偏好保留选择与已加载数据。交互约束见 [前端 spec](../specs/spec-frontend.md)。

### 3.6 长截图交付边界

保留 GDI 捕获与唯一 JS Worker 追踪/提交真源，原图按已确认增量片段保存；稳定探针用于收尾，不阻塞正常滚动采集。输入优先原生穿透，有界 FIFO 保留中间重叠帧，歧义/丢失/超限安全拒绝，预测不写入正式图片。会话失效、编辑接管与输出共享资源释放路径；通用竞态和分层约束见 specs。

## 四、复用与范围边界

复用配置/CM/广播、CapabilityRegistry、宿主 HTTP、公共输出/编辑链路及现有追踪、关键帧恢复、回放和坐标换算。

本版不扩展地图/GIS、自动定位、分钟降雨/AQI、插件市场/沙箱、网络路由修改、Firefox 导入、POST/复杂搜索模板或主窗一键更新 UI。全局网络改造由 0.27 承接。

长截图按用户优先级结束本轮：不实施 WGC 替换、追踪算法 Rust 迁移、横向采集、无重叠自动补图、末段采集并行及 Pin 分块资源交接。困难页面与自动滚动增强保留为 [roadmap「长截图困难页面与自动滚动增强」](../roadmap.md#长截图困难页面与自动滚动增强低优先级) 的低优先级候选；这些方向不计为已交付能力，也不构成本版未完成项。

## 五、子版本实现总结

### 5.1 0.26.0 — 公共底座

拆分参数、模型、供应商与展示，修复 Open-Meteo 单位、天气代码、日期和复制摘要，统一预算、取消与错误。

### 5.2 0.26.1 — 地点闭环

实现地点搜索、候选确认、手工坐标和默认地点保存；配置补丁、CAS 与密钥恢复保护跨窗口提交。

### 5.3 0.26.2 — 和风天气

接入专属 Host/Key、GeoAPI 与天气 v1，实况/逐日并行聚合，统一来源、当地日期和错误。

### 5.4 0.26.3 — 彩云天气

接入 v2.6 签名、区域坐标适配与综合结果；缺失和账号权限不足明确反馈，解析器可独立选择。

### 5.5 0.26.4 — 缓存与稳定性

实现有界缓存、预算兼容合并、独立取消和配置代次隔离；单侧失败返回 partial，迟到结果不污染新请求。

### 5.6 0.26.5 — 配置与公共交互

完成凭据自动保存、显式降级、来源/时间/地址展示、全文悬浮与错误复制，并同步双语指南。

### 5.7 0.26.6 — IP 网卡与多出口

完成物理/增强网卡快照、IPv4 国内/国际主备、IPv6 单组、排序及缓存/节流，边界见 §3.4。

### 5.8 0.26.7 — 统一列表导航

完成滚轮偏好事务迁移、通用设置入口及跨来源导航，机制见 §3.5。

### 5.9 0.26.8 — 悬浮预览与列表展示

列表返回有界正文前缀与真实字数，全文按需读取。文本、错误和图片共用左侧触发、延迟离开和视口避让；选区仅覆盖复制，菜单持有所属条目快照，迟到图片/菜单不能覆盖新内容。

### 5.10 0.26.9 — 剪贴板文件条目

建立 CF_HDROP 采集、路径历史、复制语义写回及清理闭环；单次剪贴板快照只选一类有效格式。路径历史按条数/载荷双上限治理，执行绑定条目引用；文件访问采用路径防护与独立有界 I/O。图片范围由 0.26.11 扩展。

### 5.11 0.26.10 — 剪贴板条目右键智能操作

完整 URL、单绝对路径或单文件按内容派生打开/定位操作，多文件不批量打开。展示过滤与执行门禁一致，菜单按内容代次校验；DB 故障不回退当前剪贴板，旧菜单点击不得执行新数组位置的操作。

### 5.12 0.26.11 — 剪贴板文件独立筛选与多格式原图预览

完成全部/文本/图片/文件筛选、三表游标分页和键盘循环。PNG/JPEG/GIF/WebP 按 magic 原始字节直出，WebView 负责显示；静态图转存才完整解码，动画图仅预览。转存返回实际 image_id 接续钉图/编辑，输出回调校验选择代次。

**维护教训**：预览不能按未经实测的估算 RGBA 占用拒绝正常图片；预览字节上限与转存解码预算分开。普通 PNG 转存支持逐行取样，入库保留原 PNG；预算不是所有预览的统一门槛。

### 5.13 0.26.12 — 快捷超链与自定义搜索引擎

WebEngine 使用 app.weblinks 配置、keyword 校验与既有 Open URL 执行链路；无参打开主页，带参按 UTF-8 编码替换查询。seeded 区分首次生成和用户清空；EngineTakeover 携带命中 keyword，不让引擎自行剥离参数。浏览器导入见 0.26.21。

### 5.14 0.26.13 — 浏览器书签引擎

Chromium 多 profile 书签后台建立有界内存索引，默认 bm 独占，混排默认关闭；文件指纹与代次守卫避免重复扫描/旧结果提交。来源图标按需提取。书签仅用于本地搜索，不注册 AI/MCP 能力。

### 5.15 0.26.14 — 托管 Everything 运行时

按 asset-lock 下载隔离的 Everything 1.4 实例，命名 IPC 窗口与持有句柄的 exe 路径核验归属；启动监督/stop 不在状态锁内长等待，run_id 使旧任务失效。显式 UAC、Job Object 和专属 INI 保护生命周期。

**维护教训**：静默启动用 -startup，INI 必须有 Everything 段头；HTTP 有响应不能证明实例归属或索引就绪。原双端口配置已被 0.26.23 取代，运行时仍区分用户与托管实例。

### 5.16 0.26.15 — 调整优化专项

设置拆分搜索/托管页，统一安装与状态渲染；命名实例恢复先于读写 INI 和选端口，回环 HTTP 绕过代理。补齐引擎触发词、超链主页、浏览器图标、长列表排序与编辑反馈。无服务不假设已有慢扫索引，空托管索引允许回落本地扫描，显式停止保持生效。

### 5.17 0.26.16 — 剪贴板置顶与本体窗口贴入

文本/图片/文件共用限时置顶、惰性过期、清理豁免和三元游标；置顶随内容编辑转移，复用列表节点必须同步新内容/徽章。置顶经列表管理专用命令执行，避免普通动作收尾隐藏主窗；贴入放行同进程目标并在主窗出现前保存前台锚点。

### 5.18 0.26.17 — IP 插件流控与参数提示协议

IP 使用 500ms 防抖与有界并发；args.hints 由 Router 单一真源生成列表引导和 Ghost 补全，Mixed/Takeover 共用规则，别名回写规范触发词。引导项与同批占位共存，不能被误判为此前已到的真实结果；通用协议见后端/前端 specs。

### 5.19 0.26.18 — 对话窗口侧栏与全局键位放宽

对话侧栏默认展开，hide/show 会话内保留，重启恢复默认。扩展 OEM 标点、方向键和导航键，前端归一、IPC 校验与注册层以共享向量约束；旧 Arrow* 名称兼容，chord 独占仍只吞字母。录制拒绝显示具体原因，主热键保存失败有 UI 反馈。

### 5.20 0.26.19 — 许可入口与指南重写

嵌入官方 Everything License 并幂等补偿安装目录，关于页提供开源声明。cherry-markdown token 限定在组件作用域，补丁记入 vendor 版本清单；双语指南改写为用户操作，并修复目录滚动高亮、截图工具栏顺序和提示。

### 5.21 0.26.20 — 更新提醒：静默检查与版本提示

共享检查服务与内存状态，后台延迟/节流、建议槽只填空位、按版本 dismiss；关闭自动检查不阻止手动操作。设置关于页按激活而非预热初始化检查，托盘同步版本提示。检查更新经 ReturnItems 返回后端构造的本地化结果，前端通用占位/回流；协议见后端 spec §4.5 与前端 spec §5.1。

### 5.22 0.26.21 — 浏览器搜索引擎导入与超链列表滚动

Chromium Web Data 复制临时副本后只读扫描，TemplateURL 转为既有查询模板；不支持的高级 token/协议明确跳过。勾选、改 keyword、冲突校验及保存复用原写队列/CAS/热更新，不新增第二写路径。扫描用 importSeq 丢弃旧响应，删除后立即重绘列表。Firefox、导出和默认搜索提供商语义未纳入。

### 5.23 0.26.22 — 长截图连续采集重构与技术债清理（已收尾）

连续 GDI 采样与输入解耦，采集区原生穿透；控件/失败降级保留有界转发，删除选区内拦截再补发滚轮。Worker 串行追踪和提交，有界 FIFO 保留中间帧；活跃采样周期至少 100ms、空闲 250ms，并按实测成本自适应降频。

仅为新增/替换片段生成缩略图，复用历史缓存；预览跟随已确认位置，整数边界绘制消除小预览横线。统一完成/编辑/输出/取消，尾部未确认可重试；近期静止证据复用一轮观察，仍采两张新尾帧、保留点击后观察及截止时间。长图编辑共享只读底图，移除闲置整图遮罩，输出画布编码结束即释放；编码回调校验编辑会话代次。

调试入口默认隐藏，版本号连续点击七次显示；sessionStorage 仅记住当前窗口会话，刷新保留、新会话重置，不改诊断开关值。版本号保持普通光标，自动检查更新位于关于页首项。
