# Blink 0.4 — 意图路由层

> **范围**:正式的意图路由 `IntentService` + Context 层 + BuiltinEngine

---

## 核心设计决策

**呈现权与触发正交**：命中后插件如何占用返回区，和「query 算不算命中」是两个独立维度

| surface | 含义 | 典型场景 |
|---|---|---|
| `inline` | 混排，按 score 排序 | 低优插件 |
| `priority` | 置顶（score 抬高），保留其他结果 | 天气/翻译 |
| `takeover` | 独占，跳过本地引擎 | 精确意图 |
| `auto`（默认） | 无参 → priority / 带参 → takeover | 绝大多数插件 |

**向后兼容**：旧 manifest `exclusive: true` → Auto；`false` → Inline

## 已完成 ✅

### 意图路由
| 项 | 说明 |
|---|---|
| RuleRouter | keyword 精确/前缀/regex 匹配，中文首拓名复用 `text::pinyin_initials` |
| Takeover/Mixed 策略 | Takeover 跳本地引擎，Mixed 按 surface 混排 |
| surface 总闸 | `surface_takeover_enabled` 全局开关 |
| 占位项 | Takeover 空窗时同步返回 `"正在查询…"` |

### Context 层
| 项 | 说明 |
|---|---|
| ContextSnapshot | 唤起瞬间采集前台应用 + 剪贴板 |
| 采集时机 | `window::invoke()` 中 `show()` 之前，确保拿到唤起前的前台应用 |
| 传递给插件 | `PluginQueryContext` 扩展：foreground_app / window_title / clipboard_text |
| 隐私 | 只读剪贴板，敏感内容仅驻留内存，不入 SQLite |

### BuiltinEngine
| 项 | 说明 |
|---|---|
| 内置动作 | 打开设置/锁定/关机/重启/睡眠/清空历史/退出 |
| 实现 | 纯 Rust，无需插件进程，走 sync lane |
| 扩展方式 | `ACTIONS` 数组加条目即可，纯数据驱动 |

## 穿插修复

- priority 排序不稳定 → 前端按 score 降序重排
- 窗口超出屏幕底部 → resize 后 clamp_to_work_area
- takeover 空窗 → 同步占位项 + 自动移除

## 没做什么（边界明确）

| 项 | 归属 | 理由 |
|---|---|---|
| Intent 语义枚举 | P3 | 0.4 只需「呈现调度」Route，语义分类等 0.9 AI 路由 |
| AI 路由（原 VectorRouter） | P3 | 0.9 起接入；向量召回 / RAG 后来撤销版本规划，见 roadmap 远期观察 |
| 空 query 历史 top-N | 跳过 | 产品角度非必要 |
| 上下文感知路由 | 推迟 | RuleRouter 尚未使用 snapshot |
