# Blink 0.20 — 高频内容与视觉工作流（Clipboard, Capture & Color Workflow）

> **范围**：便签与上下文建议可预测性、剪贴板独立模式深化（多选批量/快捷键）、图片编辑多来源闭环、截图交互性能与像素精调、来源无关的颜色解析与图片配色核心、便签管理与任务栏辨识。
>
> **状态**：✅ 0.20.0–0.20.9 全部完成。
>
> **动机**：0.19 完成剪贴板独立模式、图片编辑会话解耦和多屏截图/DPI 基础后，高频日用链路仍存在异常预填、跨页内容不能批量流转、图片编辑入口不完整、截图交互帧偏重、配色结果缺少可直接使用的角色与输出格式等问题。0.20 聚焦"捕获 → 筛选 → 编辑 → 复用"。
>
> **前置**：0.15（截图与取色配色）、0.16（剪贴板图片、内容编辑器与便签）、0.17（便签回收站与剪贴板来源）、0.19.7（图片编辑会话解耦）、0.19.15–0.19.16（剪贴板独立模式与多屏截图/DPI 收敛）。
>
> **原则**：不改变 Alt+Space 主链路预算；弱上下文不隐式写入用户内容；剪贴板多选状态不污染普通搜索；批量复制失败时不覆盖原剪贴板；大图片不走 Base64/JSON 热路径；截图坐标统一使用 bitmap 物理像素；颜色识别只接受确定性字面量；颜色算法只有一个 Rust 真源；图片编辑只保留一个会话核心。
>
> **范围拆分说明**：Action 全量分流、统一功能目录、调用来源类型墙与 AI/MCP 出口管理独立进入 [0.21](./0.21-capability-unification-feature-catalog.md)。0.20 只新增 `analyze_image_palette` 一项纯分析 Capability，复用现有 Registry、ImageStash 与图片会话。

## 二、背景与防误改澄清

用户问题（0.20 立项时）：空闲 Alt+S 可能带入旧选区；剪贴板只能逐条复制；历史图片和早期 pin 图不能进编辑器；截图拖选帧偏重；颜色值无一等结果、图片提色缺少角色与可粘贴输出；便签右键缺管理入口、非置顶便签任务栏全显示"便签"。

### 明确不是问题的（防止误改）

- `display_pages`（一次加载几页）与普通 `page_size`（每页几项）职责不同，不合并；历史总数不足时末页不满是正确行为。
- SelectionCache 继续作为 Awareness 数据源，只是 Alt+S 不隐式消费它。
- 角色色/基准色数学配色是两类结果：四组原图方案只返回真实像素色；显式基准色方案允许生成新颜色（标记 `source_kind=generated`），UI 分层标识。
- 便签首行标题派生算法（Rust/JS/spare 重置）早已存在，0.20.8 修复的只是 `sticky-*` capability 未授权 `core:window:allow-set-title` 的运行时拒绝。
- 长截图不支持配色提取是有意设计：拼接图只存在前端，为低频配色编码/上传/暂存大图不划算；入口直接禁用。

## 三、横切决策（定案速查）

### 3.1 Alt+S：输入框文本预填，不读选区缓存（已定）
输入框有文本则预填便签，为空则创建空白便签；不读取 SelectionCache、默认高亮或剪贴板。理由：已输入文本是强信号，缓存选区是弱信号，弱信号不隐式预填。

### 3.2 批量复制只选文本且原子提交（已定）
多选集合只接纳文本项（图片无选择态）；所有 LazyCopy 成功且 generation/epoch 有效后才 `\n` 拼接单次写剪贴板；任一失败不修改原剪贴板。

### 3.3 图片编辑单会话且拒绝替换（已定）
同一时刻只有一个编辑会话；已有会话时新入口激活旧编辑器并提示，不静默替换未保存标注（`AlreadyActive`）。

### 3.4 配色首屏强调可用结果，格式与模板分层（已定）
首屏四组只含原图真实像素：图片主题色、视觉焦点色、均衡/界面关键色、原图智能搭配（正文对比度 ≥ 4.5:1、非文本强调 ≥ 3:1 为硬门槛，不满足降级而非伪造颜色）；显式基准色数学方案进"更多方案"并标"非原图提取色"。HEX/RGB/HSL 是全面板共享格式；"每行一个"/CSS variables 是批量复制模板，收进复制菜单，不与格式混列。

### 3.5 配色分析是 Capability，选区与吸管是 Interaction（已定）
`analyze_image_palette`（`image_ref | png` 输入、结构化 Items 结果）归 Capability；拖选/吸管/精调/面板生命周期归 Interaction。本地截图面板**零回传**：普通截图只传 bitmap `x/y/w/h + epoch`（后端从 Screenshot SESSION crop），编辑器来源只传会话选区（后端从 Image Editor SESSION 取 PNG），禁止 Canvas RGBA/PNG/Base64/JSON 回传完整图片。

### 3.6 配置迁移只向前（已定）
`display_count` 只向 `display_pages` 单向迁移，不双写、不支持降级；旧 managed id 一版内作只写 alias。

### 3.7 剪贴板快捷删除只作用 active 单项（已定）
`Alt+E` 编辑 active 文本项（复用 `edit_text_item`）、`Alt+D` 删除 active 单条文本/图片（复用单删命令）；空查询裸 `Delete` 等价 `Alt+D`，非空查询保留输入框前删。IME composition 放行；修饰键要求纯 Alt（排除 AltGr=Ctrl+Alt）。多选集合只服务批量复制，不做无确认批量删除。

### 3.8 独占模式内抑制 chord 触发（已定）
AI/剪贴板/命令三模式内 chord 触发一致屏蔽（提示与触发路径对称）；唯一例外 AI 模式 Alt+Q（`promoteToChat`）。实现链路：`MainViewContext.clipboard_mode` 参与 `chord_exclusive_eligible()` → 前端 `reportContext()` 上报 → hook 不建立/退出 native 独占会话；前端 `onChordTrigger` 放行冒泡给模式自身快捷键。

### 3.9 颜色预览与多行颜色列表（已定，0.20.9）
剪贴板文本预览换行显示可见标记 ⏎（U+23CE）：原文无空格直接拼接（`foo⏎bar`），有空格两侧各保留一个；`\r\n` 归一为单次换行；保持单行布局。多行颜色列表（如配色面板"每行一个"复制格式）由 `parse_color_list` 识别：按行 split、忽略空行、每个非空行须为颜色字面量、行数 2~8；Rust/JS 输出一致（fixture `color_list_cases` 对拍）；ClipboardEngine 检测 `meta.preview`，经 `SearchItem.color_list_hex` 透传 `AppEntry.is_color_list`，前端渲染一排小 swatch。单行走普通 `parse`，超 8 行不显示 swatch。

### 3.10 chord 待命态 IME readOnly 兜底（已定，0.20.9）
首次唤起时 native 独占会话建立有竞态窗口（`window.visible` 翻转期间 hook 不吞字母键），中文 IME 下字母会进候选窗（前端兜底对 229/组字放行）。修复采用前端兜底：`input-state.js::projectUi()` 在 chord 待命态（altDown && chordEligible）设 `queryEl.readOnly = true` 禁用 IME 组字，由 `INPUT_STATE_CHANGED` 事件驱动（与窗口竞态解耦，独占模式天然豁免）；退出待命态恢复并 `focus()`；`lifecycle.js` 的 SHOWN/HIDDEN 调 `forceClearReadOnly()` 兜底 WebView 收不到 keyup 的残留。项目不使用 IME 禁用 API（ImmAssociateContext 等），"屏蔽输入法"是 hook 吞键的副产品 + 本条 readOnly 兜底。

## 四、复用与范围边界

### 4.1 主要复用
`StickyService`/spare 窗口生命周期；SelectionCache（仅 Awareness）；ClipboardEngine LazyCopy（延迟拉全文不进搜索热路径）；`results.js` 结果渲染（模式上限 + 选择投影，不复制渲染器）；`ImageEditorSession` + 两个 SESSION（截图 crop / 编辑器 PNG，只传坐标）；`CapabilityRegistry` + `ImageStash` + `image_input`；PinImage 窗口稳定引用；`ss-selection-geometry.js` 坐标真源；`kbd.js`/i18n/toast 共享反馈；`edit_text_item` 与单删命令（键盘只分派不复制逻辑）。

### 4.2 不进 0.20（含理由）

| 项 | 理由/后续 |
|---|---|
| Action 全量收敛、功能目录、来源类型墙、AI/MCP allowlist | 独立进入 [0.21](./0.21-capability-unification-feature-catalog.md) |
| 多设备同步 | 涉及加密、冲突和删除传播 |
| 文本+图片复合剪贴板批量写入 | Windows 格式协商复杂，首版只做文本 |
| CSS 命名色、渐变、设计 token 文件解析 | 防止污染搜索并控制范围 |
| 配色收藏/账户/云端 AI 配色；ASE/Figma 等文件导出 | 不做设计内容平台；先验证列表和 CSS variables 是否足够 |

| 独立颜色窗口、本地文件/拖拽入口 | Capability 可消费 `image_ref | png`，本版不新增文件选择 surface |
| 长截图配色提取 | 见 §二防误改清单 |
| 无头图片变换 Capability/MCP 编辑 | 需另行设计可观察输出和权限 |

## 五、子版本实现总结

### 0.20.0 — 便签与上下文可靠性
`StickyService::close_note(id, final_content, expected_updated_at)` 单事务原子关闭：内容 trim 后为空物理删除、非空进回收站；revision 冲突/存储失败不关窗、内容保留。Alt+S 按 §3.1 语义。`derive_sticky_title`：首条非空行、剥 Markdown 前缀/行内标记、48 Unicode 字符截断、空内容回退"便签"；保存/置顶/spare 借用回收时同步 title 与 skip-taskbar，回收重置防继承。`is_non_prose_structured_text` 负向分类（颜色/UUID/hash/版本/IP/邮箱/CSS/短 JSON/命令参数/代码标识符各为独立纯函数，禁总括式"像代码"正则），置于 `needs_translation` 前。动作错误统一投影 helper：结构化错误 → 本地化消息 → toast/status；日志不记录正文。共享 `sticky/palette.js` 消费颜色 id 与 CSS token。

### 0.20.1 — 剪贴板页数配置与模式上限
契约：`clipboard.display_pages: 1..=20, default 3`，`effective_limit = display_pages × page_size`。旧值 `ceil(display_count / page_size)` 换算钳制；新旧并存新字段胜出；首次保存只写新字段。剪贴板模式独立 `ResultLimitPolicy`，`results.js` 在模式内不被本地 `maxResults` 二次截断；热更新只影响下一轮搜索。

### 0.20.2 — 跨页多选与原子批量复制
`clipboard-selection.js` 纯 reducer：`selectedKeys: Set<hitId>` 为唯一真源 + anchor/epoch/generation；重渲染只投影 CSS。键盘：IME 优先放行；`Ctrl+Space` 切换当前文本项；已有选择时 `Shift+方向` 跨页扩展；空 query `Ctrl+A` 全选返回文本、非空保留输入框全选；有选择时 `Ctrl+C` 批量复制。批量：并发上限 4 拉取，全部成功且 generation 有效后 `\n` 拼接单次写入；退出/换 query/隐藏递增 generation 使旧请求失效。Esc 顺序：IME/菜单 → 清多选 → 退模式 → 隐藏。右键删除后保持模式内刷新（维持页号与光标）。

### 0.20.3 — 确定性颜色字面量
`src/domain/color.rs` 与 `frontend/js/shared/color.js` 同契约：`#RGB/#RGBA/#RRGGBB/#RRGGBBAA`、`rgb()/rgba()`、`hsl()/hsla()`，alpha 末位，half-away-from-zero 舍入；仅完整 trim 字符串可解析（不支持命名色/渐变/变量/局部颜色）；Rust/JS 共读 `color-literals.json` fixture 对拍。`ColorEngine` sync-lane：可解析即返回 priority 结果，不 takeover、不进网络/AI。`createSwatch` 统一 renderer（棋盘底 + 色块 + 边界），主窗口与剪贴板共用。剪贴板文本项前端降级识别（name 恰为颜色字面量时也显示 swatch）。

### 0.20.4 — 图片编辑多来源闭环
`ImageEditorService::open(CurrentClipboard | ClipboardHistory(image_id) | PinWindow(label))`，domain 只传受控 id/label 不传 Base64；统一转 `PinImage::{Png,Bgra}`。资源限制：输入 ≤ 32 MiB、尺寸 ≤ 16384、解码 RGBA ≤ 256 MiB，阻塞解析/编码进 `spawn_blocking`。已有会话返回 `AlreadyActive`（激活旧编辑器 + 提示）。pin registry 改窗口 label 持有稳定 `Arc<PinImage>` generation 引用，原子替换、窗口销毁释放，不再依赖最近 8 项缓存。历史图片/pin 右键直接按 id/label 进编辑器，不覆盖剪贴板；取消只结束 editor session。

### 0.20.5 — 截图静态底图与交互性能
捕获底图只在 session 初始化/来源切换绘制的静态层；动态 interaction canvas 只画遮罩/边框/手柄/尺寸提示/准星/放大镜，拖动缩放只清该层；标注 canvas 生命周期独立。鼠标物理坐标 IPC：single-flight + 30Hz 上限 + generation 门禁，同时最多一个在途。高速框选暂停放大镜采样，取色/低速/精调恢复。验收基线：拖动期间完整底图 `drawImage` 0 次；4K 单屏动态层 frame p95 < 16.7ms；坐标 IPC ≤ 30 次/秒。

### 0.20.6 — 像素精调与取色冻结
状态机 `Idle/SelectingNew/Moving/Resizing/ColorPickerFollowing/ColorPickerFrozen/Annotating`，事件只由当前状态消费；文本输入/IME 优先于截图快捷键。`ss-selection-geometry` 纯函数：1 bitmap px 移动 + 边界钳制、resize Shift 1:1 约束（仅新建/resize，不改方向键步长）、准星步进。取色 following 滚轮进入 frozen 并调倍率；frozen 内鼠标/方向键只移准星不解除；Enter 确认、Esc 逐级退出；真实鼠标移动不自动跳回过期位置，显式退出才恢复跟随。

### 0.20.7 — 配色单一真源与可用输出
`src/domain/palette.rs` 是聚类（OKLab、确定性 seed、K=3..8、≤32 次迭代、中心映射最近真实像素）、角色、智能搭配（正文 ≥ 4.5:1 / 强调 ≥ 3:1 硬约束，亮度阶梯/色相协调/候选可靠度/色度预算/两两距离评分，无合格组合返回结构化低置信不伪造）、OKLCH 数学方案（显式 anchor 才生成新色，sRGB gamut mapping，标记 `generated`）、对比度与格式化的唯一真源；删除前端 `palette-core.js`/`palette-worker.js`，禁双算法；阈值集中在版本化常量，变更须更新 golden fixture。`analyze_image_palette` Capability：`image_ref | png` 二选一输入、结构化 `Items`（AI/CLI/MCP 只读纯净 data）、资源预算/`spawn_blocking`/deadline/错误映射。本地零回传链路见 §3.5。前端保留薄层：120ms 防抖 + palette epoch 竞态校验、渲染与复制投影；面板交互按 §3.4 分层。

### 0.20.8 — 便签入口、任务栏辨识与剪贴板键盘短路径
便签右键"便签管理"复用顶部同一 `showStickyManager()` 入口（无第二套状态）。`capabilities/secondary-windows.json` 为 `sticky-*` 补最小 `core:window:allow-set-title` ACL，并加静态验证防文档与运行时再失配。剪贴板快捷键按 §3.7：`clipboard-shortcuts.js` 无 DOM 判定 helper（纯 Alt/大小写/IME/AltGr·Alt+Shift 拒绝/目标解析），`clipboard-mode.js` 分派 active 项动作，删除成功模式内 reload + reconcile 清理多选 key。独占模式 chord 抑制按 §3.8。

### 0.20.9 — 收尾修复
四项（详见图 §三 3.9/3.10 与下述）：
1. `preview_line` 换行显示 ⏎ 标记（§3.9），替换原"换行压成空格"。
2. 多行颜色列表多色 swatch：`parse_color_list`（Rust/JS 对拍）+ `SearchItem.color_list_hex` 透传 + 前端 `.color-list-swatch` 一排 16px swatch（CSS 宽度自适应，覆盖 `.app-icon` 的 24px 固定宽）。
3. 截图颜色面板 hover 误关修复：颜色面板是点击式二级页面，但工具组 dropdown 的 hover `mouseenter` 调 `closeAllDropdowns()` 会连带关闭它；`closeAllDropdowns({ includeColor })` 增加
参数，hover 路径传 `false`，document 点击外部 / canvas mousedown / selectTool 仍关闭。
4. chord 待命态 IME readOnly 兜底（§3.10）。

## 八、遗留与已知问题

- 多行颜色列表超过 preview 80 字符截断（如 8 行 `hsl(...)` 长格式）时不显示 swatch——`make_preview` 截断使最后一行不可解析，属优雅降级，不影响复制内容。
- chord 首次唤起的 native 会话建立竞态本身未在后端根治（`window.visible` 翻转时序），0.20.9 的 readOnly 是前端兜底；若后续做后端同步置位可移除兜底，但建议保留 readOnly 作为防御层。
- 批量删除、复合格式批量写入、多设备同步等仍按 §4.2 排除，推进时需新 phase 立项。
