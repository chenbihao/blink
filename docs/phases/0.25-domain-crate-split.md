## 二、背景与动机

单 bin 增量验证约 36.8s，拆分使热点域可独立验证。体验专项来自实际使用：配置显示与行为不一致、翻译和更新排障困难、MD 丢内容、剪贴板上屏失败、历史浏览受一次性上限限制、位置被旧回调覆盖。

**不是问题的**：builtins 依赖多个域，留在同一 domain crate 是有意取舍；常用系统入口是维护的功能目录，基础应用扫描仍来自开始菜单；功能启用与系统快捷键注册成功分别展示；UIA 能否识别输入框不能决定是否允许用户显式粘贴。

## 三、核心决策与维护要点

### 3.1 粗拆 domain，协议错误先独立

顺序为 infra → capability-error/config/local-engine → stt → domain。协议主体与 builtins 随 domain 搬移，避免强拆循环依赖；bin 保留 re-export shim。STT 配置只接收 provider 的 id/kind/base_url 投影。

依赖库不带 `cfg(test)`，测试存储以 `runtime_mode` 隔离，生产入口显式激活。通用规则见 [后端规范 §二](../specs/spec-backend.md)。

### 3.2 后端确认值驱动回填，字段 CAS 保护写入

欢迎页/设置页先订阅再首读，事件/焦点共用单飞刷新；保存、录制、草稿编辑期间暂停回填。分片从最新值合并目标字段，保留未知字段，损坏数据拒绝默认回写，冲突返回 `config_conflict`。

release 自启动依次查询→注册→核验→保存→广播，失败补偿系统原状态，补偿失败明确报错；debug 只保存偏好。系统注册与数据库没有共同事务。

### 3.3 系统入口按稳定身份合并，启动目标必须明确

常用与发现目录共用 entry_id、独立历史 key、别名/拼音匹配与类型化启动目标；同目标不同语义保持独立。发现仅读本机设置 XML 可靠子集，DeepLink 白名单校验，缺目标/未知条件/歧义项跳过，不能凭 PageID 猜 URI。

执行只接受 entry_id 并核验当前来源状态；主窗与 `search_apps` 共用目录投影 RunAction/Invoke，AI/MCP 默认授权关。发现默认关，后台单飞以 generation/目录指纹保护提交。

### 3.4 一键更新：官方 updater 与签名发布链路（0.25.10）

锁 updater 2.12 兼容 Tauri 2.11.5。公钥入配置，私钥仅 CI secret 与本地 `~/.tauri/blink-updater.key`；**必须异地备份，丢失会阻断存量用户验签升级**。xtask 生成 latest.json/签名制品，publish 后更新才可达，镜像不放宽签名校验。安装后台单飞、进度节流，检查早退复位等待态；debug 禁止安装。

### 3.5 浅色主题专项（0.25.11）

颜色引用收敛到语义 token，`--yellow` 正式化，Latte 状态色保留色相并向黑缩放至可读。截图/Pin 暗色 palette 自持。theme-debug 聚合 token/组件/对比度，关闭即隐藏；第三方主题遗留见 §6.3。

### 3.6 程序化输入滚动跟随（0.25.12）

整串写入统一设光标到末尾并调用 `ghost.scrollWithMargin()`，partial 的 rAF 跟随不变。录音 input/ghost 同步右 padding 避让实测指示器宽度，preview 裁切到避让带。通用规则见 [前端规范 §5.8](../specs/spec-frontend.md)。

### 3.7 翻译错误透出与显式降级（0.25.13）

错误包含供应商根因，stderr 按级别转发。`no_space` 由用户点击移除，不自动改写密钥；插件读取 trim 兼容存量。`allow_fallback` 默认关，开启才允许降级并展示顺序。引擎/降级标记放 desc，避免污染 AI 可见译文；批量全失败报错，部分失败附计数，不能拿原文冒充译文。

### 3.8 预选挖洞与就绪前拖选（0.25.14）

预选用四块 DOM 遮罩与整数几何，开关默认开、桌面回退共用，图片编辑不启用；拖动/确定态接管时强制隐藏预选遮罩。未 ready 缓存 pointerdown 并 capture、持续预览，ready 后仍按住才衔接，提前松手放弃。

窗口列表未就绪不能判桌面，完成后用唤起时光标补选；多屏局部重绘。**同值赋 canvas.width 也清画布，必须跳过。** 夜灯/HDR 采集色差、确定态 DOM 化留后续。

### 3.9 CM 命名 v2 与自愈迁移（0.25.15）

SecretRef 标识模块/主体/用途，keyring target modifier 指定 `blink:{module}:{subject}:{purpose}`。v1 通过原 keyring Entry 读 UTF-16LE，v0 仍 raw UTF-8；跨代迁移先确认编码。

启动全量枚举后 Rust 过滤，不依赖 Win32 通配语法；写 v2 成功才删旧项，每启动自愈覆盖旧版并行/备份恢复。测试用自有内存 store，不碰真实 CM。

### 3.10 插件密钥宿主统一拦截（0.25.16）

manifest `secret:true` 在唯一写入口转存 CM，SQLite 留空串、前端不回显，插件 stdin 注入前还原；启动幂等搬迁存量。每查询读 CM 暂不缓存。CM 写失败告警但不落明文，可重存；降级至旧版表现未配置，密钥仍在 CM。数据清理包含插件命名空间。

### 3.11 编辑器 MD：内容保全优先于字节保真（0.25.18）

统一 parser/JSON/空白口径，按内容块锚点区间重建 patch，空段与块增删改共用换行规则。默认最小 patch 保原文；复核失败用整篇序列化并提示规范化，保持可编辑；仅载入无法对齐或序列化异常才只读。

纯空白段、围栏字符、空引用等存在序列化器不可往返形态，规划器不能补救已丢信息。原文+位置映射保默认路径字节，内容安全优先。MD 内部滚动、徽章悬浮；残留 `win.show()` 已清理，ACL 教训见 [架构规范 §A7.4](../specs/spec-architecture.md)。

### 3.12 脚本解释器是托管制品（0.25.20）

编译期锁 Python 3.12.10 embeddable / Node 22.11.0 win-x64 制品信息；显式安装走 single-flight/staging/SHA-256/zip slip 防护/自检/原子 promote，启动清扫避开活跃 staging。未安装不回退 PATH，错误指向设置安装。

不进模型引擎注册表，Python 限标准库/插件自带文件，不做 pip/npm/venv。RuntimeType/manifest 兼容，echo 示例仅 dev 默认禁用；下载受控重复待第三处使用再收敛。

### 3.13 剪贴板治理：真实粘贴与可信定位（0.25.21–0.25.25）

1. **诊断**：show 前焦点快照与 `debug_uia_focus`，不记 Name/Value；Document=50030，Unicode CRLF 合并一次回车。
2. **显式上屏**：固定原 HWND/PID/线程→写剪贴板→隐藏→等物理修饰键释放→恢复复核→Ctrl+V，终端按类名改 Shift+Insert。目标无效/恢复失败/超时仅复制，不搜索控件/强制 SetFocus；互斥到后台结束。语音 G2 strict 独立。
3. **筛选**：全部/文本/图片共用 chips 与 Tab/Shift+Tab，kind 下推跳过另一表；IME/Alt+Tab 放行，切换清选择/作废旧响应，图片筛选不显示颜色字面量。
4. **多选**：Enter 按点击顺序拼接上屏，Ctrl+C 批量复制，Alt+数字/双击单条；原子取数缺项整体放弃。
5. **定位历史**：0.25.25 鼠标落点与后续整窗居中，**均已被 0.25.29 普通主窗搜索栏基准取代**（§3.17）。可信文本校准保留，定位和粘贴许可分开。

### 3.14 竞态与测试收尾（0.25.25）

输入变化立即作废旧请求，防抖只延迟发送；旧上屏不清新 UI。测试跨 crate 存储隔离，有界等待检查任务失败；OCR waiter 验广播结果，worker 注入短测试超时而保生产默认值。

xtask 构建后按包并行 Rust/doctest/前端，可回退并行数；MSVC rustdoc 对齐静态 VC/动态 UCRT，不跳示例。规则见 [后端规范 §二](../specs/spec-backend.md)、[前端规范 §5.1](../specs/spec-frontend.md)。

### 3.15 长图 pin 可见性与拖动 DPI（0.25.26）

长图顶边可出屏，mini 进入前钳制工作区并同步 imageScreen 锚点，防 reconcile 拉回；异步校验动画 generation。JS screenX/Y 是 CSS 增量，按 DPR 换物理位移，DPR 翻转先以旧尺度结算再重定基准；拖动期跳过 onScaleChanged reconcile，松手/watchdog 收敛。不逐事件 IPC 查指针屏，跨屏微差为有界取舍。

### 3.16 中英指南双端渲染（0.25.28）

`docs/guide.md` 中文真源、`guide.en.md` 英文翻译，GitHub 在线和 `include_str!` 内嵌共用文档。内嵌随版本走，在线链接提供最新版；不复制到 resources，避免 dev 预构建。xtask 结构校验、Rust 双语章节对齐防漂移。

设置复用 Cherry/导航/窗口，欢迎/关于直达。语言切换重建正文/目录，英文标题 ASCII 保双端 slug。同一目录必须带 inner 容器；窄窗收起区包含于展开区，鼠标激活 blur、键盘保焦点；覆盖 vendor break-all 避免英文任意断词。

### 3.17 剪贴板流式加载、热配置与定位会话（0.25.29）

**加载**：三 kind 共用 `(created_at, id 字符串)` keyset，All 两表归并、多探测一条判断 has_more。SQL、匹配截断、Rust 归并同序；不能先 fuzzy 高分截断再按时间游标推进，否则漏新记录。文本查询仍受 retention/candidate 窗口约束，不宣称全文无限搜索。

首批两页、追加一页；游标就绪后显式预取，旧追加成功/失败/finally 均校验所属请求。追加去重保序、不按批内 score 重排，删除局部移除保浏览深度；Ctrl+A 实时选已加载全部文本（0.25.31 扩展为全部历史类型）。会话最多 2000 条，display_pages/旧一次性展示上限退役，单批仍有防异常上限。

**滚轮/设置**：仅显式 page 整页，其余默认 step；仍每屏 page_size 条、Alt+1~9 对当前视口，PageUp/PageDown 始终整页，step 方向键越界移一条。滚轮按单位换算，配置/查询/会话切换清余量。默认 180 天、文本 10000、图片 1000，hint 只写默认值；功能配置在键绑定上方，见 [前端规范 §5.9](../specs/spec-frontend.md)。

**配置链路追加修复**：主窗先订阅再启动读取，所有模式 SHOWN、可见切模式与 CONFIG_CHANGED 共用单飞刷新，旧响应不能提交；结果/Chord 移除独立启动读取，Chord 动作回流也验配置 revision。原剪贴板 SHOWN 提前返回和内存默认 page，是“配置逐条却仍整页”的直接原因。

设置页 change 边沿捕获字段，快速操作串行并暂停回填，只发字段 patch/确认基线。后端 CAS 保其他偏好/未知字段，损坏配置拒绝默认回写，监听开关共用合并路径。保存和运行时投影后立即广播；仅期限/上限变化清理历史，展示项不等待清理。热切滚轮只改行为/提示，页大小重绘当前视口，不重开模式、清选择或重查已加载列表。

**定位最终规则**：唤起前捕获 owner/鼠标/焦点；无可信文本锚点时，与普通主窗共用鼠标屏与搜索栏基准，内容向下展开、越界才上移。整窗居中及 owner 屏优先兜底**已被本规则取代**。首帧只复用剪贴板真实布局尺寸，不借普通搜索/AI 高度。

主线程唯一入口提交位置/尺寸；SHOWN 与只读快照恢复模式，resize 携 revision/递增 sequence，隐藏/旧会话拒绝。首批 ready 后才异步校准，限 250ms、当前前台、未交互；方向确定后不随高度翻转。Document 普通选区/只读/证据未知不当 caret，GetSelection 只接受明确可编辑零长度插入点；控件近似仅紧凑 Edit。键入/点击/滚动锁原点，语音策略不变。

**会话修复**：旧追加不阻塞新查询；删除、编辑器/便签打开、单条全文回流校验会话，不能清新选择、隐藏新窗或向新目标发起旧粘贴。clamp 读/判/写整体主线程串行，避免旧位置覆盖新布局。

### 3.18 剪贴板混选与按类型操作（0.25.31）

选择统一使用显式 `{kind,id}`，由搜索投影携带，不再从 action/hitId/lnkPath 猜类型；不同类型同 id 不碰撞。选择模块只管理身份、锚点、区间与会话；类型操作表决定菜单目标和计数，未知类型不会落到文本分支，后续文件/音频需添加对应类型适配。

普通点击单选，Ctrl 切换，Shift 按完整已加载顺序选区间，Ctrl+Shift 追加区间；重复 Shift 会缩放同一锚点区间。右键已选项保留组、未选项单选；Ctrl+A 包含全部已加载类型。文本纯选保留复制/上屏/编辑/便签快捷键，混选从右键显式操作文本或图片子集，默认操作不静默丢弃图片。Alt+D/空查询 Delete 删除选择，无选择时删 active；原 0.20 §3.2/§3.7 限制被本版取代。

删除与批量钉图通过本地 `manage_clipboard_history` Capability 收敛，旧单项命令保留为适配入口。按类型分库事务、逐项报告结果；成功项局部移除保浏览深度，失败项保留且提示，不宣称跨库原子性。图片逐张读取和打开，不预载整批 PNG；每批最多 16 张，相对上张成功位置偏移，单张失败继续，其余并发请求明确报忙。

批量任务冻结条目引用、epoch 和选择 revision，仅原会话可回流，且只有 revision 未变时清理选择；主窗隐藏不取消后端已开始的资源任务。右键菜单携独立 menuId，点击/关闭均核验，旧索引不能执行新菜单动作。复制/粘贴/编辑仍校验异步代次，不能清新选择或隐藏新窗。
