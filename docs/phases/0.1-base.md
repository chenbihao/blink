# Blink 0.1 MVP — 实现总结

> 技术栈：Rust 2024 edition + Tauri 2.x + WebView2

---

## 已完成 ✅

### P0 — 基础交互

- **全局热键**：Alt+Space tap/hold 状态机（`WH_KEYBOARD_LL`），不影响系统组合键
- **悬浮窗口**：无边框、置顶、弹性大小、显示器跟随
- **焦点管理**：看门狗轮询（150ms）+ grace period，覆盖 IDEA 终端等不发 deactivate 的窗口
- **IME 支持**：微软拼音/搜狗/微信输入法已验证
- **ESC/失焦隐藏**：全局 ESC + 看门狗

### P1 — 搜索 & 计算

- **应用搜索**：开始菜单 `.lnk` 扫描，nucleo fuzzy + 拼音首字母
- **历史权重**：SQLite 频率统计，log 加权排序
- **实时计算**：evalexpr，整数转浮点避免截断
- **搜索缓存**（0.2.0 补完）：内存索引 + 后台预扫 + mtime 增量失效

### 基础设施

- 单实例（`tauri-plugin-single-instance`）
- 托盘常驻 + 右键菜单
- 设置页（通用/快捷键/存储/调试/关于）
- i18n 中英双语
