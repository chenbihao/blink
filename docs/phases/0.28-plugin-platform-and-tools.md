## 二、背景与保留的设计

本版将固定插件集合扩展为可安装、可撤销、带独立页面与数据集的官方工具体系，并补齐配置同步及“录制素材 → 编辑 → 按格式导出”的工作流。

0.28.26–0.28.27 来自截图标注与 FFmpeg 下载反馈（画笔缺点击连直线、箭头尖端凹口；慢速源长期占用主源、部分下载入口未接镜像候选）。0.28.28 来自使用反馈（AI 追问竞态报错、划词组合提问缺入口、同步后供应商列表不刷新）。三项均已实施收口，问题定位过程留 git log。

**维护澄清**：独立插件窗口不等于独立 EXE、WebView2 环境或常驻后端；页面可以无后端。WebDAV 协调和高频采集仍由宿主承担。MP4 直接复用原始素材，无需先生成 GIF；实时涂画直接入帧，不构成可事后编辑的标注轨。FFmpeg 安装也不代表已交付通用转码、外部视频预览或录音机。

通用规则见 [架构 spec §A7.5](../specs/spec-architecture.md)（插件信任边界）、[后端 spec §4.6/§7.7/§十](../specs/spec-backend.md)（生命周期、同步、媒体任务与长素材）和 [前端 spec §1.4/§5.1](../specs/spec-frontend.md)（窗口、主题与竞态）。

## 三、核心决策与维护要点

### 3.1 官方分发与插件生命周期

生产仅接官方目录，IP/天气/翻译随包，词典为可选线上插件。**0.28.4 的随包词典与 0.28.5 的预构建词库分发已被 0.28.13 客户端自举取代**。官方更新可覆盖随包版，卸载更新可回退且保留配置/授权；词典无随包回退。卸载默认保留数据，可显式清除，PendingRemove 冻结首次清理意图。

目录采用固定官方 HTTPS 端点与包 sha256，尚无独立目录签名；stale 缓存只供展示。dev 本地源独立于官方缓存并记 LocalDev，生产拒绝本地安装。发布走独立 `plugins-catalog` Release；`cargo xtask pack` 生成四款插件及 catalog，不再发布词库包。

运行代次复核活动 Arc 句柄身份；AI 工具缓存取授权集合与实际注册条目的交集。tool id 稳定是契约，schema 改变本身不强制重新确认。

### 3.2 独立窗口、主题与会话

每插件默认一个主窗口，single-flight 创建并复用，预算 6 个；超限优先回收隐藏最久的窗口。ready 前保留最新载荷，更新/禁用/卸载撤销页面。

翻译/词典每次唤起均重置查询、方向与引擎，再预填新载荷；正文不跨重启保存，取代早期“重开恢复会话”方案。声明 pages 的插件可由主窗触发词空参回车开首页，缺密钥/词库时仍可显示修复引导；IP 独立页已移除。

`blink-plugin` 服务活动包资源，`@host` 提供 SDK 与主题基础。曾因只注入主题层、请求不存在的 auto.css 导致整窗失去样式，须验证实际页面。页面身份取调用窗口 label；当前受限桥接依赖官方页面可信，隔离范围以架构 spec 为准。

### 3.3 翻译方向与会话

方向为人工本次覆盖 → 当前窗口会话 → 已保存默认。缺省 auto（中→英，其他→中）；配置加载时一次性将旧默认 zh 升级为 auto，之后人工固定目标及原有 en/ja/ko 保留。query、单次 tool、有序 batch 共用实现，旧返回形态保留；未知源语不伪装可靠检测。新载荷用 epoch 隔离旧请求，单次选择不回写设置。

### 3.4 词典、数据源与客户端自举

`builtin.dictionary` 的源码、页面与构建器集中于 `plugins/dictionary/`。ECDICT 提供英汉、基础汉英、词形/短语，wordroot 提供可选词源；源修订、许可及质量真源见 [DATASETS.md](../../plugins/dictionary/DATASETS.md)、`bootstrap.json` 与 `quality-samples.json`。源为固定 commit 的 CSV/wordroot，不依赖不存在的 `ecdict_csv.7z` Release 资产。

宿主下载和管理操作，插件工作线程构建，宿主以 `active.json` 原子挂载并记 Managed。missing/corrupt/outdated 自动准备，兼容旧库跳过构建，可重建修复；可选词源失败不阻塞基础查词。

“查词/dict”确定路由；精确词头/词形、短语优先，拼写池按首字母/词长召回，距离优先、同距离再按词频。中文反查限常用概念，缺词源不以 AI 填事实。主窗每插件最多一个在途查询和一个最新待查输入；前缀走词头索引范围。双击英文浮卡有独立 epoch。

**踩坑**：BufWriter 未 flush 曾导致真实 stdio 恒超时；dev 修改随包 Rust 插件后需重编 `target/debug/`，不能用旧 debug exe 覆盖已安装包，也不能把词典源码目录当已安装插件。

### 3.5 固定范围 WebDAV 配置同步

手动同步到自动建立的 `blink/`，范围以 `config_sync/portable.rs` 为准：偏好、快捷键/入口、插件可移植设置、Provider/模型非秘密参数、提示词库与超链。秘密、授权、设备状态和用户内容留本机；未提供端到端加密。

按稳定 item id 与独立 `$order` 三方合并，保留共同基线、本机覆盖及 10 份本地备份；插件分片删除不传播，未装插件设置休眠。远端为不可变 `snapshots/<revision>.json` 与条件更新的 `head.json`，纯追赶不重写远端。

WebDAV 客户端留在 domain，避免 infra 反向依赖域类型。**提示词库在 AI 库**，服务使用 config/AI 双池；读错库曾触发 `no such table`，不能伪装成空配置而引发批量删除。密码使用固定长度掩码，不沿用 API key hint。

### 3.6 录制素材、时间轴与导出

采集/过载/素材/编码归 infra，domain 管非破坏时间轴。采集与 zstd-1 压缩经有界队列协作，时间戳决定帧时长，暂停不入成品；删帧同时移除对应时长。修剪、删帧、速度、停留、循环及 undo/redo 均投影源素材，导出冻结 revision。

**历史替代**：初版 120 秒/512MiB 等短素材门禁、全量预载和单文件存储已由 0.28.25 的分段/分页与空间保护取代（§5.9）；初版独立控制窗已由 0.28.23 统一 overlay 取代（§5.7）。历史 `gif-*` 模块/IPC 名保留。

高熵帧压缩比可为 1.00×，不能把压缩当资源保证。`gif_start_recording` 必须 async，避免同步建窗与 WebView2 初始化互等；GDI 区域/光标采用虚拟屏物理坐标，IPC 使用 camelCase。

### 3.7 FFmpeg 可选托管运行时

扩展 `managed_runtime`，安装一次供宿主媒体功能共用，任务时启动独立进程、空闲不常驻；不套 STT/OCR 的 EngineDefinition 或伪模型。Windows x64 锁定 Gyan 9.0.2 essentials，包含 ffmpeg/ffprobe，不带 ffplay、不回退 PATH。

安装与同版本修复均新建 slot，自检通过后原子切换，失败保留旧版；status 不启动进程。所需软件编码器实际自检决定就绪，未安装不影响原有 GIF/语音输入。当前采用 7z 分发，旧 ZIP 同构建安装保持兼容，见 §5.4。

### 3.8 共享媒体任务

infra 管类型化参数、进程/管道、采样、编码与验证，app 管调用方、会话、任务身份、运行时租约和事件。编辑器导出仍属 Interaction，不向 AI/MCP 开放任意 FFmpeg 命令。全局一个重型任务，估算为可抢占低优先级任务；通用预算、取消、提交及租约要求见后端 spec §十。

进度读取结构化 `-progress`，不解析 stderr 百分比；任务关联 job/session/revision/构建身份，输出逐帧流入，不生成整段原始视频或全量 PNG。正式导出抢占估算时等待旧进程、管道和租约回收，最多 10 秒，期间禁止迟到估算抢槽。

### 3.9 GIF/MP4 格式适配

格式中立毫秒快照分别适配 GIF 与 MP4，直接读取原始素材。**0.28.19 的无声/固定 30fps 方案已由 0.28.24/0.28.25 的音轨及多档帧率取代**。MP4 使用软件 H.264/YUV420，按累计有效时间采样、默认匹配素材名义帧率，支持 10/15/24/30/60fps；总时长误差至多一个输出帧，不逐源帧取整累加。

缩放保持比例，奇数尺寸补偶数边；超编码能力明确拒绝。MP4 单次播放且可带声音，GIF 保留独立 10ms 延时/循环/调色板/差分语义，不含声音但保留原音轨。格式选择联动后缀、画质、进度与统计。安装引导保留编辑，由用户返回后重新发起导出；成品需元数据和完整解码验证，再原子提交且默认不覆盖。

### 3.10 截图工具栏与二维码

默认常驻翻译 → 长截图 → 录制 → 保存 → 问 AI → 钉图；更多仅默认收纳 OCR 文本面板、二维码、翻译并钉图，复制/取消固定最右。OCR 阅读图层仍负责直接选字，收纳不等于关闭 OCR；引擎不可用时保留显式入口与反馈。

布局用稳定动作 id 和两个有序分区保存，截图内/设置页共用编辑器，支持跨区拖动/键盘排序；窄屏从常驻尾部临时收纳，不写回配置，WebDAV 仅同步布局。二维码从原图本地解码，面板复用 OCR 定位而状态独立；识别与打开是两次显式操作，执行复用现有 Capability，不借道建议排序。动作白名单及预算见 §5.6。

### 3.11 统一浮栏与手动涂画

最终由截图 overlay（`chord-screenshot`）承担同一浮栏与透明绘图层，未新建独立浮栏窗；复用标注引擎可避免跨窗通信与两套定位。`recording-session.js` 单模式派生同一 DOM，右侧展开标注，左侧锚点不跳变；原三类录制辅助窗已删除。

涂画直接且仅一次合成入帧，不保存标注事件轨。受支持截图标注转入录制局部坐标，模糊/马赛克等未适配效果阻止开始并保留返回处理入口。进行中笔画、半透明单次合成、动态桌面和控制面排除须一起回归，不能依赖 DWM 顺带捕获叠层解释成品。指针/焦点与编辑恢复见 §5.7。

### 3.12 双源音频与同一时间轴

默认无声，可选麦克风、系统声音或双源；默认设备策略在每次启动解析为实际端点，指定设备失效不静默回退/热切换。双源独立素材与电平；任一来源失败在共同有效边界暂停全部来源，更换同类设备后核验并手动继续。

采集静音丢弃对应在途真实样本，只保留静音描述，录后不可恢复；编辑器静音/音量是可撤销混音设置。修剪/删帧同步剪声音；延长停留补静音，缩短保留原区间前段，再全局保音调变速，不重复人声填停留。素材与 STT 会话分开，麦克风租约互斥，细节见 §5.8。

### 3.13 长录制与资源保护

取消固定时长、累计帧数和素材/成品大小的产品限额，保留有界解码、队列、缓存、并发及按规模计算的任务期限。分段素材、分页索引、增量编辑/撤销/草稿和惰性导出一起改造；共同检查点按画面与应有音轨的有效前缀恢复，不能只放宽前端限额。

实际素材占用、增长、可用空间及目标盘需求分别呈现；低空间共同暂停，释放空间后手动继续或停止。大小估算是有界抽样范围提示，不是预留或成品大小保证；执行中继续检查空间。实现参数见 §5.9，支持矩阵与测量边界见 §6.8。

### 5.7 0.28.23 — 统一浮栏与录制编辑器

#### 5.7.1 同一浮栏与状态

`recording-session.js` 以 screenshot/ready/starting/recording/paused/stopping 派生同一 `#toolbar`，`drawing` 仅管标注展开/接收指针。开录清静态底图，保留透明 overlay、画布与范围框；点阵抓手只移工具栏，手形联动区域。后端成功后提交状态，拖动不续录；重复截图恢复当前控制，窗口丢失停止并保留素材，session/epoch 防迟到重入。

#### 5.7.2 实时涂画与指针

复用画笔/箭头/形状/文字/数字/高亮/橡皮及撤销/清空。二进制标注快照经 `gif_overlay_annotation` 合成，首快照和透明层就绪后启动；清空/撤销只影响后续帧。桌面模式整窗穿透，后端 16ms 轮询命中矩形（前端 250ms 上报）临时放行工具栏交互；涂画模式接收指针。默认不抢焦点，文字输入时申请/归还聚焦，输入框置区域下方，录制态 Esc 不退出会话。

#### 5.7.3 录制编辑器与定位

用户名称统一“录制编辑器 / Recording Editor”，内部 label/IPC 不迁移。进度条按有效时长前缀二分定位，支持点击/拖动/键盘/悬浮预览；拖动暂停并在松手后恢复原播放态，只移播放头、不改编辑多选。预览/缓存有界，按会话/revision/请求序号拒绝旧帧。

#### 5.7.4 最近录制与草稿恢复

最近列表分页读取轻量摘要及可见首帧，不打开每条完整索引；主窗通过 `open_gif_editor` Capability 复用编辑器，有会话优先激活，无会话进首页，不默认向 MCP 开放历史。切换前 flush，有导出时先确认取消，不静默打断。

`draft.json` 保存素材身份、revision、修剪/删帧/停留/速度/循环/播放位置及音轨混音；800ms 防抖，关闭/切换前 flush，原子写且旧 revision 不覆盖、删除后不复活。损坏/不兼容回退原素材并提示，不持久化 undo 栈。关闭保留工作，显式丢弃/删除才清理，仍属 72 小时临时素材，浏览不刷新全部 TTL。

### 5.8 0.28.24 — 双源音频

cpal WASAPI 麦克风/loopback 共用 PCM 转换、块时钟、RMS/峰值底座；录屏固定 48kHz 双声道 PCM16，STT 仍为 16kHz 单声道。16 包有界队列、250ms 检查点及 100ms 在途余量，记录设备原生格式与分段。电平节流传数值；源 WAV 经受限 `blink-recording-audio` Range 协议，不传全段 JSON。

`AudioSpan` 以原始毫秒区间映射有效时间，连续区间合并；统一绝对播放时钟校正声音，预览/MP4 使用同一裁剪、补静音、混音及保音调变速。AAC/所需滤镜自检和完整解码纳入提交门；共同前缀恢复不改写源尾部，设备失败/未提交音频不能冒充正常静音。

**踩坑与门槛**：零延迟回调须按整块时长回推起点并按样本裁定有效边界，否则电平/录音可能全零。默认设备按 Windows 默认接口和端点 ID 解析，不能取列表首项；本机每应用虚拟麦克风覆盖曾导致误选，清除 Blink 输入覆盖后用户确认 USB 正常。产物音视频时长容差 100ms、音频流起点门槛 50ms，编辑器偏差超过 40ms 校正；这些不等于硬件实测同步精度。

### 5.9 0.28.25 — 长素材、空间与 60fps

- **存储/编辑**：v2 约 64MiB 数据段、32 字节定长索引与原子共同检查点，兼容 v1 只读；静帧周期提交有效时长。索引按 256KiB 窗口读、缓存两窗；共享区间/差量撤销（128 步/约 8MiB）、轻量导出视图及压缩区间草稿，避免全量帧号与快照复制。
- **空间保护**：单帧解码保留 64MiB，采集队列按字节约束。预留取 256MiB 与“2×在途队列 + 5 秒增长量”较大者，并以一秒原始帧流量兜底；空间查询失败/低空间共同暂停。目标盘与声音中间文件盘分别复核，固定短素材/成品/任务期限门禁已统一移除。
- **高帧率**：保留 GDI SRCCOPY、光标/叠层合成，复用 DIB 和 zstd 上下文，高帧率双 worker 错峰读取。采集/MP4 支持五档帧率并反馈实际值；累计时钟防漂移，GIF 按累计 10ms 分组，超长静帧拆 delay。
- **估算**：最多三个邻域、96 源帧、6 秒内容抽样；GIF 考虑重复帧，MP4 声音采用含容器余量的保守范围并列 PCM 额外空间。参数代次隔离与导出抢占复用共享任务，见 §3.8。

**踩坑**：迟到/相同毫秒时间戳不能写零/负时长；音频区间与全局变速不能按每帧毫秒取整。FFmpeg 9 的旧 `-filter_complex_script` 已失效，改用 `-/filter_complex` 读取受控文件；移除大小上限时不再传 `i64::MAX` 给 `-fs`，执行期空间检查保留。

- **配置语义**：通用页「优先使用国内镜像下载」默认关闭、不随 WebDAV 漫游，与代理设置互不覆盖（network 分支字段补丁）；显式 `BLINK_HF_ENDPOINT` 最高优先级；镜像与官方候选必须同一摘要/签名，不信任镜像提供的新校验值；每任务固定偏好快照，切换只影响新任务。
- **预算与日志**：连接/响应等待、响应体停滞、整任务分别设预算；低速切换经预热与持续窗口确认并限制次数；日志统一脱敏（URL 去 query/签名、路径隐身份），按开始/响应/切源/结束节点记录，速度诊断限频，不逐 chunk 刷日志。
