# Blink 0.15 — 截图标注体验重做（Alt+A Screenshot Redesign）

> **范围**：重做 Alt+A 截图体验，覆盖标注工具、长截图闭环采集、顶层窗口吸附与像素检查。
>
> **状态**：✅ 已完成。
>
> **动机**：截图是 Blink 的高频 chord surface，需要在不牺牲主链路响应和数据正确性的前提下，补齐标注、长截图与精确选区体验。
>
> **前置**：0.11 标注能力；0.14.7 截图模块拆分与 OCR 基础设施迁移。
>
> **原则**：无 bundler；未确认的长截图帧不污染结果；定位不确定时拒绝猜测；截图像素与回放数据默认不持久化、不进入日志。

---

## 一、实现总结

0.15 完成了三条截图体验主线：

- **标注体验**：重做工具栏与 per-tool 配置，补齐文字、数字标号、高斯模糊、聚光灯、局部放大、马赛克双模式、截图取色、主色与 harmony 配色，并完成 pin 反馈收尾。
- **长截图**：建立“滚动—稳定—抓帧—确认”的单生产者闭环，支持双向有坐标拼接、分层重定位、丢失保护、离线回放、结构化诊断、自适应自动滚动，以及独立预览与公共输出链路。
- **选区增强**：增加顶层窗口吸附、像素检查器、坐标/尺寸提示，并统一物理屏幕、bitmap 与 CSS 坐标换算。

本 phase 只保留最终实现结论和维护索引；实施过程、反馈轮次与逐条验收见 git 历史。

## 二、核心决策

### 2.1 标注命令与配置

- `TOOL_CAPS` 描述工具能力；笔画、画笔、文字和效果分别持有独立配置。
- 影响重放的模式写入 command，undo/redo 不依赖易漂移的全局模式。
- 数字标号从可见命令栈推导序号；preview 与 final render 使用同一语义。
- pin 保留左上角缩放锚点，缩放提示固定定位，不随图片缩放漂移。

通用前端维护约束见 `spec-frontend.md`。

### 2.2 长截图闭环与正确性

前端持有唯一采集闭环：

```text
滚动一次 → 灰度探针等待稳定 → 抓取完整帧 → 定位与拼接确认 → 下一轮滚动
```

手动和自动滚动共用稳定检测与全帧确认。每个确认帧携带长图坐标 `top`；正常路径匹配上一确认帧，失败后依次通过附近关键帧、方向相关的全局关键帧和已拼接内容分区重定位，再以原分辨率参考确认。低置信或大跨度跳转需要迟滞/连续帧确认；无法消除歧义时进入 `lost`，保留已确认内容并暂停自动滚动。

灰度指纹只负责候选召回，不能单独确认远距离跳转。一次滚入完全未采集区域且没有视觉重叠时，不推测或补造缺失内容。

### 2.3 回放、诊断与自动滚动

- 生产采集与离线回放共用 `tracker.js` 的定位决策；7 组 fixture 覆盖连续向下、回顶、快速丢失恢复、重复纹理、局部动画、无重叠和滚到底。
- 匹配决策记录候选来源、分数、重叠率、置信度、坐标、追加区间及拒绝原因。诊断默认关闭；只有开发者显式开启并导出时才把帧写入本地日志目录。
- 自动滚动以实际确认位移和置信度反馈调节 wheel 幅度；连续低置信、页面持续运动或配准失败时暂停并保留结果。

### 2.4 长截图会话与模块边界

`ScrollCaptureSession` 是长截图状态、代际、定时器、wheel 队列和在途任务的唯一所有者。退出、重置、失焦、取消与 overlay 重载共享失效和清理路径；预览不参与匹配决策，输出复用普通截图的 PNG 编码及 pin/save/copy 分发。

采集驱动、追踪决策、自动滚动、回放、诊断、拼接、稳定检测、会话与预览分别位于 `scroll/` 子模块。`ss.scroll*` 访问器作为兼容门面保留，真实状态只存在 session。

### 2.5 顶层窗口吸附与像素检查

- overlay 打开时一次性通过 `EnumWindows` 枚举顶层窗口，过滤不可见、cloaked、tool/noactivate、自进程与桌面目标，并使用 `DWMWA_EXTENDED_FRAME_BOUNDS` 获取边界。
- 前端缓存按 Z-order 返回的窗口矩形并纯 JS hit-test；吸附只显示虚线预选框，不改变区域亮度。
- 按下后移动不足 3 CSS px 采用窗口矩形，达到阈值则转为自由框选；吸附后的 HWND 可供长截图优先使用。
- 像素检查器显示 9×16 网格、物理坐标与中心色值；mousemove 只记录位置，采样、绘制和 DOM 定位由 rAF 节流。Shift 切换 HEX/RGB/HSL，C 复制色值。
- `ss-selection-geometry.js` 统一物理屏幕、bitmap 与 CSS 坐标换算，供选区提示、窗口矩形转换和输出裁剪复用。

本版只识别顶层应用窗口，不识别窗口内部 UIA 控件或任意视觉元素。

## 四、能力边界与后续增强

以下能力未纳入 0.15 最终范围，不作为本 phase 的未完成项：

- 横向长截图、超长图 tile 化输出；
- 窗口内部 UIA 控件吸附与基于图像分割/视觉模型的任意元素识别；
- CAP 闭环及 OCR/翻译能力增强。

现有降级策略保持：快速滚动失去全部重叠时暂停并要求回滚；重复纹理候选歧义时拒绝定位；自动滚轮无效时保留手动模式。
