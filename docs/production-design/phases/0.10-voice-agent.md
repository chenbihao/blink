### 麦克风采集:waveIn → cpal 替换

原 winmm `waveIn` API 在 Win10/11 麦克风隐私设置下采集数据全为零（静默拦截）。引入 cpal 0.18（WASAPI），回调驱动替代轮询，无 unsafe FFI。`AudioDevice.id` 从 `u32` 改为 `String`（设备名）。

## 一、两个目标

| | G1 主窗口语音输入 | G2 语音输入法上屏 |
|---|---|---|
| 触发 | tap → 再 hold | hold（无先验 tap） |
| 文字去向 | blink `#query` | 外部前台应用光标处 |
| 流式展示 | 更新 #query | mini overlay 显示 partial |
| 复用 | `chord-fill-query` 链路 ✅ | 全新建：注入通道 + overlay |

**Hold 判定**：keydown 后起 `SetTimer`，超阈值(~300ms)发 `Hold`，keyup 时若已 fire 发 `HoldRelease`，否则取消 timer 发 `Tap`。tap 路径在 keyup 立即触发，不受 timer 影响。

## 二、STT 选型（FunASR）

### 接入形态

- **云端**：OpenAI 兼容 API（`/v1/audio/transcriptions`），7 家供应商。
- **本地**：FunASR Python 工具箱的 `funasr-server`（OpenAI 兼容 API），Blink 通过 uv 自管理 Python 3.12 环境。
- **非流式**：hold → 松开 → 一次性识别。真流式（边说边出字）= 0.10.3。

### 模型

| 模型 | 中文 | 流式 | 下载体积 | funasr-server 参数 | 说明 |
|---|---|---|---|---|---|
| **SenseVoice-Small** ⭐默认 | ⭐⭐⭐⭐ | ❌ 但极快(CPU 17x) | ~234MB | `--model sensevoice` | 语种识别+情绪+声学事件 |
| Paraformer-zh | ⭐⭐⭐⭐⭐ | ❌ | ~880MB | `--model paraformer` | SOTA，时间戳+热词 |

> `funasr-server` 的 `FALLBACK_CONFIGS` 只支持 `sensevoice` 和 `paraformer`。`paraformer-zh-streaming` 不在配置中，真流式需 0.10.3 自定义 WebSocket server。
>
> 两个模型不冲突——一次只加载一个，切换改配置+重启服务即可。

### Python 环境自管理（uv）

Blink 通过 uv 自管理 `%APPDATA%\blink\python\venv\`，用户零手动操作。

**PyTorch 安装**（`--torch-backend` 一步安装）：

```bash
uv pip install torch torchaudio funasr fastapi uvicorn python-multipart --torch-backend=auto
```

> **关键**：`torch`/`torchaudio` 必须显式列出——funasr 不声明 torch 依赖（ML 包惯例），`--torch-backend` 只控制 torch 包的 index，不会自动把 torch 加入安装列表。

- CUDA 检测：`nvidia-smi` 解析（兼容旧格式 `CUDA Version:` 和新格式 `CUDA UMD Version:`）
- uv 版本兼容：检查 `uv pip install --help` 是否含 `--torch-backend`，旧版回退两步安装
- 进度流式：`install_packages_streaming()` 用 `read_until(b'\n')` + `split('\r')` 捕获 tqdm 进度条
- uv zip 解压：纯 Rust `zip` crate，无 PowerShell 依赖

### 控制台编码

子进程设 `PYTHONUTF8=1` + `PYTHONIOENCODING=utf-8` + `PYTHONUNBUFFERED=1`，修复 Windows 控制台中文乱码。

## 三、文本注入通道（G2）

### 方案：Clipboard + Ctrl+V

```
HoldRelease → STT 最终文本
  → 恢复前台窗口焦点（SetForegroundWindow + Alt 欺骗）
  → 备份剪贴板 → 设置为 STT 文本 → SendInput(Ctrl+V) → 等待 100ms → 恢复剪贴板
```

### 焦点恢复（提升注入成功率）

**问题**：`finalize()` 是 async HTTP（1-3s），期间前台焦点可能漂移到 overlay 或其他窗口。Ctrl+V 发给了错误的目标。

**修复**：
1. `start_recording` 时保存 `GetForegroundWindow()` 的 HWND
2. 注入前 `restore_foreground(hwnd)`：Alt 键欺骗 + `SetForegroundWindow`
3. 等 50ms 让焦点稳定后再 SendInput

### TSF Composition（0.10.3+ 未来）

当前 mini overlay 是"可视化 composition buffer"——hold 期间显示 partial，松开注入。未来用 TSF `ITfComposition` 实现真·原地流式（像拼音输入法的候选词），工程复杂度高（COM interop），0.10.3 再做。

## 四、STT 配置

`SttConfig` 配置分片（`ConfigKey::KEY = "stt:config"`）：

```rust
pub struct SttConfig {
    pub enabled: bool,           // 总开关（默认关）
    pub mode: SttMode,           // Cloud / Local
    pub cloud_provider: Option<SttCloudProvider>,
    pub local_engine: LocalEngineConfig,
    pub audio_device_id: Option<String>,  // cpal 设备名
    pub streaming: bool,          // 默认开
}

pub struct LocalEngineConfig {
    pub server_port: u16,         // 默认 8000
    pub funasr_model: String,     // "sensevoice" / "paraformer"
    pub device: String,           // "cpu" / "cuda"
    pub auto_start_server: bool,  // Blink 启动后懒加载启动服务
}
```

设置页 UI：模型下拉 + 设备选择并排 → 安装环境 → 自动启动开关 + 启动/停止服务 → 统一日志窗口 → 空间管理。

### 自动启动服务

`auto_start_server` 开启后：Blink 启动 5s 后自动 `start_funasr_server`。开关切换时若服务未运行也会立即启动一次。

### 语音错误反馈

服务未就绪时按住 Alt+Space：
- `start_recording` 检查 `is_server_ready(port)`，未就绪则 emit `blink://voice-error`
- G1：`#query` placeholder 显示错误消息
- G2：mini overlay 显示错误消息（先 show 再延迟 100ms emit，确保窗口就绪），2s 后自动隐藏

## 五、FunASR 服务管理

- **启动命令打印**：`tracing::info!("funasr-server 启动命令: {cmd_display}")`
- **防止重复启动**：`FUNASR_SERVER_CHILD` + `try_wait()` 检查已有子进程
- **Blink 退出自动停止**：`RunEvent::Exit` handler → `shutdown_funasr_server_blocking()`（`start_kill`）
- **tqdm 进度输出**：`read_until(b'\n')` + `split('\r')` 拆分，每段作为一条日志转发
- **CUDA 诊断**：启动前 `detect_cuda()` 打印检测结果到日志窗口

| 新增物 | 威胁 | 保证 |

## 八、架构

```
src/domain/stt/       — SttEngine trait (async) + mock/cloud/local + 模型注册表
src/infra/platform/
  audio/              — cpal/WASAPI 麦克风采集
  inject/             — Clipboard + Ctrl+V 文本注入
  python/             — uv 自管理 Python 环境
src/app/
  stt_config.rs       — SttConfig 配置分片
  voice.rs            — VoiceService 管线编排
```

### 次级窗口 Capabilities

Tauri 2 权限模型要求每个窗口在 `capabilities/` 声明权限。`capabilities/secondary-windows.json` 给 voice-overlay / chord-ball / chord-screenshot / contextmenu-popup 授权 `core:default`（事件监听 + invoke）。**不授权则 `listen()` 静默失败**。

### 波形动画（G1 + G2 共用）

`css/components/voice-wave.css` 定义 `.vw-bar` 样式：
- Rust `compute_rms`：噪声门限 0.001 + 线性映射 0.001~0.15 + sqrt 曲线
- JS：`jitter` 独立于 `lv`，静默时也有微妙呼吸
- CSS idle：`@keyframes vw-breathe` 呼吸动画，JS 设 inline style 后 `[style]` 选择器自动禁用
