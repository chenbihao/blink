## 一、两个目标

| | G1 主窗口语音输入 | G2 语音输入法上屏 |
|---|---|---|
| 触发 | tap → 再 hold | hold（无先验 tap） |
| 文字去向 | blink `#query` | 外部前台应用光标处 |
| 流式展示 | 更新 #query | mini overlay 显示 partial |
| 复用 | `chord-fill-query` 链路 | 注入通道 + overlay |

**Hold 判定**：keydown 后起 `SetTimer`，超阈值(~300ms)发 `Hold`，keyup 时若已 fire 发 `HoldRelease`，否则取消 timer 发 `Tap`。

## 二、STT 选型（FunASR）

### 接入形态

- **云端**：OpenAI 兼容 API（`/v1/audio/transcriptions`），7 家供应商。
- **本地**：Blink 自管理 Python 3.12 环境（uv），运行自定义 `blink_stt_server.py`。
- **非流式**：hold → 松开 → 一次性 HTTP 识别（SenseVoice）。
- **真流式**（0.10.3）：hold 期间 WebSocket 边说边出 partial text（Paraformer-streaming）。

### 模型

| 模型 | 用途 | 流式 | 体积 | 标识 |
|---|---|---|---|---|
| **SenseVoice-Small** ⭐ | 非流式默认 | ❌ | ~234MB | `sensevoice` |
| **Paraformer-zh-streaming** | 真流式 | ✅ | ~880MB | `paraformer-zh-streaming` |

> 两模型 lazy load，互不占用内存。非流式请求不加载 streaming 模型，反之亦然。

### Python 环境自管理（uv）

Blink 通过 uv 自管理 `%APPDATA%\blink\python\venv\`，用户零手动操作。`--torch-backend=auto` 自动检测 CUDA 选择 PyTorch 变体。进度流式输出到设置页日志窗口。

### 统一服务：`blink_stt_server.py`（0.10.3）

自定义 Python server 替换官方 `funasr-server`，统一支持非流式 + 流式 + 增强参数：

```
blink_stt_server.py（Blink venv 中，随 Rust 二进制发布）
  │
  ├── POST /v1/audio/transcriptions  ← 非流式（SenseVoice）+ 热词/ITN
  ├── WS   /ws/stream                 ← 真流式（Paraformer-streaming）
  ├── GET  /health                    ← 健康检查
  └── GET  /v1/models                 ← 模型列表
```

HTTP 端点兼容官方 `funasr-server`，`LocalSttEngine` 和 `is_server_ready_http()` 无需修改。

**FunASR 增强参数**（官方 server 未暴露）：

| 参数 | 说明 |
|---|---|
| `hotword` | 热词列表（每行 `词 权重`），存为 `hotwords.txt` |
| `use_itn` | ITN 逆文本归一化（"二零二四年" → "2024年"） |

## 三、文本注入通道（G2）

### 方案总览

| 方案 | 剪贴板 | 流式 preedit | 状态 |
|---|---|---|---|
| Clipboard+Ctrl+V（0.10.1） | ❌ 污染 | ❌ | 回退兜底 |
| **SendInput Unicode**（0.10.3 默认） | ✅ 不碰 | ❌ | ✅ 当前 |
| TSF Composition via imekit（P1） | ✅ | ✅ | 🔜 试用 |

### SendInput Unicode（当前默认）

`SendInput` 的 `KEYEVENTF_UNICODE` flag 逐字符发送 `WM_CHAR`，绕过剪贴板：
- UTF-16 编码，代理对支持 emoji
- 换行符用 `VK_RETURN`
- 分批发送（Windows 单次上限 ~544 个 INPUT）
- 失败时回退 Clipboard+Ctrl+V

### 焦点恢复

`finalize()` 是 async HTTP（1-3s），期间前台焦点可能漂移。注入前保存的 HWND → `restore_foreground`（Alt 欺骗 + `SetForegroundWindow`）→ 等 50ms 再 SendInput。

## 四、配置

`SttConfig` 配置分片（`ConfigKey::KEY = "stt:config"`）：

```rust
pub struct SttConfig {
    pub enabled: bool,                    // 总开关（默认关）
    pub mode: SttMode,                    // Cloud / Local
    pub cloud_provider: Option<SttCloudProvider>,
    pub local_engine: LocalEngineConfig,
    pub audio_device_id: Option<String>,  // cpal 设备名
    pub streaming: bool,                  // 流式开关（默认开）
    pub inject_method: InjectMethod,       // G2 注入方式（默认 SendInput）
}

pub struct LocalEngineConfig {
    pub server_port: u16,                  // 默认 8000
    pub funasr_model: String,             // 非流式模型（"sensevoice"）
    pub streaming_model: Option<String>,   // 流式模型（None = 非流式）
    pub device: String,                   // "cpu" / "cuda"
    pub hotwords: Option<String>,          // 热词列表
    pub use_itn: bool,                    // ITN（默认 true）
    pub auto_start_server: bool,          // Blink 启动后懒加载
}

pub enum InjectMethod { Clipboard, SendInput, Tsf }
```

## 五、服务管理

- **启动**：`ServerStartParams::from_config()` → 释放脚本 + 写热词 → `python blink_stt_server.py --model ... --streaming-model ... --hotwords ... --use-itn`
- **防重复启动**：`FUNASR_SERVER_CHILD` + `try_wait()` 守卫
- **退出自动停止**：`RunEvent::Exit` → `start_kill`
- **CUDA 诊断**：启动前 `detect_cuda()` 输出到日志窗口
- **自动启动**：`auto_start_server` 开启后 Blink 启动 5s 后自动启动

## 七、P0 不回归保证

| 新增物 | 威胁 | 保证 |
|---|---|---|
| Python 子进程 | 启动加载若进热路径 | lazy-link，进程启动不加载 STT |
| ~230MB 模型 | 撑爆 <300MB 预算 | lazy-load，按需下载 |
| 麦克风采集线程 | 阻塞 LL hook | 独立线程，绝不进 hook |
| Hold timer | timer 阻塞 hook | timer 仅发事件，不执行逻辑 |
| G2 文本注入 | 触发失焦隐藏 | G2 时主窗不显示，注入不抢前台 |

## 八、架构

```
src/domain/stt/
  mod.rs            — SttEngine trait + create_engine() 工厂
  mock.rs            — Mock 引擎（未启用时）
  cloud.rs           — 云端引擎（OpenAI 兼容 HTTP）
  local.rs           — 非流式本地引擎（HTTP POST → blink_stt_server）
  streaming.rs       — (0.10.3) WebSocket 流式引擎
  funasr.rs          — blink_stt_server 生命周期 + 脚本嵌入/释放
  wav.rs             — WAV 编解码 + HTTP 转录共享工具

src/infra/platform/
  audio/             — cpal/WASAPI 麦克风采集
  inject/            — 文本注入（SendInput Unicode → Clipboard 回退）
  python/            — uv 自管理 Python 环境

src/app/
  stt_config.rs      — SttConfig 配置分片
  voice.rs           — VoiceService 管线编排
  commands.rs        — Tauri IPC 命令（start/stop/diagnose）

resources/python/
  blink_stt_server.py — 统一 STT server（随 Rust 二进制发布）

# 运行时文件
%APPDATA%\blink\python\
  blink_stt_server.py — 释放后的脚本
  hotwords.txt        — 用户热词文件
  venv\               — Python 3.12 虚拟环境
```

### 次级窗口 Capabilities

`capabilities/secondary-windows.json` 给 voice-overlay / chord-ball / chord-screenshot / contextmenu-popup 授权 `core:default`。不授权则 `listen()` 静默失败。

### 波形动画

`compute_rms`：噪声门限 0.001 + 线性映射 0.001~0.15 + sqrt 曲线。CSS idle `@keyframes vw-breathe` 呼吸动画，JS 设 inline style 后自动禁用。
