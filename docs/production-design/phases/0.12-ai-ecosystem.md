### 1.2 产品边界

- 本地模型只对接外部 ollama / lmstudio，不内嵌推理引擎，不负责模型下载。
- ollama 走 rig 原生 Provider；lmstudio 和其他兼容服务走 `OpenAICompatible`。
- 0.12 不引入 MCP / RAG / 向量库。
- 安装包保持轻量，不因 AI 运行时显著膨胀。

### 1.3 两条 AI 路径严格隔离

| 维度 | 主窗口 | 对话窗口 |
|---|---|---|
| 抽象 | `AIProvider` | `AgentProvider` |
| 交互 | 单轮快路径 | 多轮对话 |
| 模型能力 | `complete` / `stream` | rig `AgentBuilder` / memory / tool loop |
| 工具调度 | 外部调度，固定回流 | Agent 内部循环，最大 50 turns |
| 记忆 | 无 | 按 `conversation_id` 隔离 |

**铁则**：主窗口 `AIProvider` 不暴露 `AgentBuilder`、memory 或 agent loop；对话能力只存在于 `agent_provider.rs` 和 chat 服务路径。

### 2.3 Provider 最终模型

- `ProviderEntry`：统一 endpoint、协议类型和密钥引用。
- `ModelEntry.capabilities`：一个模型可声明 Chat / Embedding / STT。
- `ProviderKind`：`OpenAICompatible` / `AnthropicMessages` / `GeminiGenerateContent` / `OllamaHttp`。
- 云端 STT 通过 `provider_id + model_id` 引用统一配置，不再维护第二套 endpoint 和密钥。
- Embedding 配置已铺路，实际消费留 0.13 RAG。

### 2.4 Agent Tool 适配层

```text
Capability / Action
        ↓
CapabilityTool / ActionTool (ToolDyn)
        ↓
build_agent_tools()
        ↓
rig Agent tool loop
```

- `ai_eligible() == false` 的 Action 不进入 Agent tool 池。
- Dangerous tool 在 `ToolDyn::call` 内等待用户确认，不会先返回“已执行”的假结果。
- MCP tool 在 0.13 复用同一适配层，不改现有 Capability / Action 契约。

### 5.2 SQLite ConversationMemory

AI 库新增：

```sql
CREATE TABLE conversations (
  id TEXT PRIMARY KEY,
  title TEXT,
  created_at INTEGER NOT NULL,
  last_active_at INTEGER NOT NULL
);

CREATE TABLE messages (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  conversation_id TEXT NOT NULL,
  role TEXT NOT NULL,
  content TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  FOREIGN KEY (conversation_id) REFERENCES conversations(id) ON DELETE CASCADE
);
CREATE INDEX idx_messages_conv ON messages(conversation_id, id);
```

`content` 直接存序列化的 rig `Message`，完整保留 text / tool_call / tool_result。

```rust
impl ConversationMemory for SqliteConversationMemory {
    async fn load(&self, conversation_id: &str) -> Result<Vec<Message>, MemoryError>;
    async fn append(&self, conversation_id: &str, messages: Vec<Message>) -> Result<(), MemoryError>;
    async fn clear(&self, conversation_id: &str) -> Result<(), MemoryError>;
}
```

### 5.3 上下文窗口

起步采用最近 20 条消息的滑动窗口；TokenWindow、摘要压缩和语义召回留后续版本。

持久化层保存完整历史，窗口策略只影响每次发给模型的 active context，不删除数据库历史。

### 5.4 Tool loop

AgentProvider 已配置 `default_max_turns(50)`，0.12.3 在持久化 conversation 上正式开放连续工具调用：

- UI 展示每轮 ToolStarted / ToolFinished。
- 到达 50 turns 后给出明确降级提示。
- 对话窗口始终启用 tool loop，不受主窗口 `ai_tool_result_feedback` 配置影响。
