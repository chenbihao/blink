## 核心设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| Dev 路径映射 | 运行时路径转换（非 Junction） | IDE 索引安全，纯代码逻辑 |
| 脚本插件编码 | 脚本端强制 stdin/stdout/stderr UTF-8 | 解决 Windows GBK 双向乱码 |

## 统一错误处理机制

| 错误类型 | 用户看到的反馈 |
|---|---|
| 超时 | `查询超时，请稍后重试` |
| 解释器未找到 | `未找到解释器：python，请在设置页配置` |
| 进程启动失败 | `进程启动失败：{具体原因}` |
| 进程意外退出 | `插件进程意外退出` |
| 插件主动报错 | `{插件返回的 message}` |

**设计原则**：
1. `PluginHandle::query()` 永远返回 `Ok(Vec<PluginItem>)`
2. 错误项 = 负分 PluginItem，走正常「占位符替换 → 排序 → 展示」链路
3. 四层处理：脚本端强制 UTF-8 → `PluginProcess::query()` 内部转化 → `PluginHandle::query()` 兜底 → 前端负分透传

## 脚本插件 UTF-8 处理

**Python**（必须在脚本开头，任何读写之前）：
```python
sys.stdin.reconfigure(encoding='utf-8', errors='replace')
sys.stdout.reconfigure(encoding='utf-8', errors='replace', line_buffering=True)
sys.stderr.reconfigure(encoding='utf-8', errors='replace')
```

**Node.js**（readline 必须显式设置 encoding）：
```javascript
const rl = readline.createInterface({
  input: process.stdin,
  output: process.stdout,
  terminal: false,
  encoding: 'utf8'  // 关键！
});
```

## UTF-8 字节切片防御

**Clippy 禁止危险写法**：
```toml
[workspace.lints.clippy]
string_slice = "deny"  # 直接按字节切片字符串 → 编译失败
```

**安全截断 API**（`src/text.rs`）：
```rust
let s = "这是一段很长的中文";
assert_eq!(s.truncate_chars(5), "这是一段很...");  // 按字符数截断
assert_eq!(s.take_chars(3), "这是一");             // 不加后缀
```

## 打包路径方案

| 模式 | 路径 |
|---|---|
| Dev | `exec_path()` 检测 `./bin/` → 自动映射到 `target/debug/{exe_name}` |
| Release | 正常相对路径 → `manifest_dir/bin/{exe_name}` |

manifest 统一写 `./bin/blink-plugin-xxx.exe`，Dev/Release 通用
