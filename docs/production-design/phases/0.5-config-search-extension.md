# Blink 0.5 — 配置架构 + 文件搜索 + 扩展系统

> **范围**:统一配置持久化 + FileEngine（Everything）+ 右键菜单 + 主题系统

---

## 核心设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 配置表结构 | 单表 KV，分命名空间 | 0.x 不过度工程，单表支撑到产品化 |
| 配置热生效 | 各模块内部 AtomicUsize/RwLock | 避免重启，零时序问题 |
| 插件配置 | `{enabled, settings}` query 内联透传 | 改完即时生效，无独立状态同步 |
| settings_schema | manifest 声明，设置页自动渲染表单 | 零代码即可为插件加配置 UI |

## 配置 key 清单

| key | 说明 |
|---|---|
| `app_config` | 核心配置（hotkey/threshold/grace/theme/history...） |
| `engine:file_search` | Everything 端口/启用/结果上限 |
| `engine:builtin` | 内置动作开关 |
| `engine:calc` | 计算器配置 |
| `plugin:{id}` | 插件独立配置（enabled + settings） |
| `context:config` | 上下文层总配置 |

## 热生效表

| 配置项 | 方式 |
|---|---|
| log_level | tracing reload |
| plugin enabled | filter_route 过滤 |
| plugin settings | query 内联 |
| file_search | 引擎内部更新 |
| theme | 各窗口 shown 时读取 |
| max_results | AtomicUsize 更新 |
