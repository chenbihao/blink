## 1. 三分钟上手

| 操作 | 触发 | 说明 |
|---|---|---|
| 唤起 / 隐藏主窗 | `Alt+Space`（轻点） | 键位可在设置中修改 |
| 搜索 | 直接输入 | 模糊匹配 + 拼音首字母 + 全拼（`wx` 微信、`dksz` 打开设置），IME 组字期间不打扰 |
| 选择结果 | `↑` `↓` / 鼠标悬停 | 跨页边界自动翻页 |
| 打开结果 | `Enter` / 单击 | 按结果类型启动应用、复制或执行动作 |
| 快速触发 | `Alt+1` ~ `Alt+9` | 直接激活当前页第 N 项（主窗内按住 `Alt` 会显示每项的数字角标） |
| 采纳补全 | `Tab` | 输入 `fy` 出现灰影 `fanyi `，按 `Tab` 采纳，直接开始输入翻译内容 |
| 隐藏窗口 | `Esc` / 点击窗口外任意处 | 失焦自动隐藏（AI 生成中除外） |

主窗打开时**按住 `Alt`**，输入框内（空输入时）或底栏（有输入时）会显示当前可用的 Chord 快捷动作键帽，不需要背：

| 组合 | 作用 |
|---|---|
| `Alt+Q` | AI 对话窗口（主窗有输入文本时，文本自动带入对话输入框） |
| `Alt+A` | 区域截图（仅空输入时） |
| `Alt+C` | 剪贴板历史（空输入显示全部；有输入时当前输入转为过滤词） |
| `Alt+E` | 编辑当前内容（优先级：结果项 > 输入框 > 系统划词 > 空白编辑器） |
| `Alt+S` | 钉为便签（取输入框文本；空输入创建空白便签） |
| `Alt+Space`（按住） | 语音输入，松开出字 |

每个 Chord 动作都可以在设置中改键，并提升为**全局快捷键**（主窗隐藏时也能触发）。

## 2. 主窗口与搜索

| 操作 | 触发 | 说明 |
|---|---|---|
| 翻页 | `PgUp` / `PgDn`，或结果区**滚轮** | 上滚=上翻页，下滚=下翻页，保持页内相对位置 |
| 双槽建议 | `Tab` / `Shift+Tab` | 主建议与次建议各占一键；也可直接点击建议行 |
| 命令模式 | 输入 `>` 开头 | 独占模式，回车在终端执行命令；退格删掉 `>` 退出 |
| 计算器 | 直接输入算式 | 出现 `= 结果` 项，`Enter` 复制结果 |
| 剪贴板召回 | 输入 `剪贴板` / `clip` / `jtb` | 不用 `Alt+C` 也能拉出剪贴板历史 |
| 空闲上下文建议 | 复制了 URL / 刚划词后唤起 | 建议条自动给出「打开链接 / 问 AI / 翻译划词」，并标注内容来源 |
| 右键菜单 | 右键任意区域 | 剪切/复制/粘贴/全选、Chord 快捷入口、从搜索文本创建便签、便签管理、设置、退出 |
| 结果项右键 | 右键结果条目 | 打开所在文件夹、复制路径/文件名、打开快捷方式目标、重置该项启动频率记录等 |
| 拖动主窗 | 按住卡片空白区拖动 | 移动主窗位置（没有任何视觉暗示，但空白处真的可以拖） |

### 天气

#### 配置地点

- 进入 **设置 → 插件 → 天气配置**，点击现有地点卡片中的“更换地点”，即可在卡片面板内搜索。可用两位国家码或上级行政区缩小范围；选中完整地点候选后保存整张卡片。温度单位也会随设置明确保存。
- 搜索面板中的“搜索来源”可选择解析服务：自动（已配置和风时优先和风，否则 Open-Meteo）、Open-Meteo 或和风天气。切换来源后旧候选立即失效，不会回流；选中的地点候选只在保存后生效。和风来源需要先配置 API Host 与 API Key，显式选择和风而未配置时会明确报错，不会静默换用其他来源。
- 高级用法可以手动填写 WGS84 纬度和经度。显示名称留空时，地点会以坐标显示。
- 取消编辑不会写入更改。清除默认地点也会同时清除旧城市，避免它继续作为备用地点。
- 天气插件关闭时仍可手动编辑地点卡片与配置；联网搜索需要先启用插件。旧配置中的 `default_city` 仍兼容查询，但会显示为尚未确认，查询不会自动改写它。若编辑期间设置发生冲突，面板会加载最新配置；请重新核对并确认草稿。

#### 切换天气来源（和风天气 / 彩云天气）

- 在 **设置 → 插件 → 天气配置** 中选择“天气来源”：Open-Meteo（免费无需配置）、和风天气或彩云天气。切换来源保持已保存的默认地点与温度单位不变。
- 和风天气需要先在[和风开放平台](https://console.qweather.com/)创建项目获取 API Key，并在“设置 → 控制台设置”中复制账号专属的 API Host，分别填入插件的“和风 API Host”（形如 `https://abc123.re.qweatherapi.com`，只填服务根地址）与“和风 API Key”。API Key 保存在系统凭据管理器中，留空表示不修改，点右侧按钮可清除。
- 彩云天气需要先在[彩云开放平台](https://platform.caiyunapp.com/)创建应用，把“App Key（令牌）”与“App Secret（API Secret）”分别填入“彩云 App Key”与“彩云 App Secret”。两者都按凭据保存在系统凭据管理器中，留空表示未修改，点右侧按钮可清除；App Key 只能包含字母、数字与 `.` `_` `~` `-`。
- 未选择对应来源时其凭据不生效；选择和风/彩云但凭据不完整时，查询会返回“需要先配置”的明确错误。修改凭据后的下一次查询立即使用新配置；鉴权失败会明确提示，不会自动换回 Open-Meteo。
- 彩云天气对中国大陆地点使用 GCJ-02 坐标、大陆以外（含港澳台）使用 WGS84。Open-Meteo 搜索到的地点会按国家代码自动判定；手工坐标与和风候选需要在此确认——编辑地点面板中的“坐标区域”选择“中国大陆”或“中国大陆以外”后保存即可。未确认区域的地点在彩云查询时会被明确拒绝并提示如何补充，不会凭坐标粗略猜测。
- 免费额度、7 天逐日权限与有效期以彩云控制台实际显示为准；实际返回天数不足 7 天时，结果会说明实际可用天数，不会虚构数据。
- 和风实况与 7 天预报并行请求；彩云使用单个综合接口同时返回实况与逐日。一侧/一块数据不可用时按实际可用数据返回部分结果并说明缺失项。结果中会显示数据来源，回车可打开来源与使用声明页。

#### 查询与结果

- 查询未指定地点时使用已保存的默认坐标；天气工具显式传入 `city` 或 `location` 会覆盖默认地点，两者不能同时传入。`search_locations` 只搜索并返回候选（可传 `resolver` 指定解析来源），不会保存地点。
- 地名有歧义时会要求补充上级行政区或完整地点，例如“辽宁/朝阳”或“广州/天河区”，不会自动选择第一项。Open-Meteo 对中文名称可能没有结果，可尝试完整区县名或英文名称，也可手动填写坐标；同名地点不一定都能自动唯一识别。
- 工具调用显式指定温度单位时，优先于设置中的单位；当前天气与逐日预报统一使用该单位。复制天气结果会复制完整天气摘要。
- 缺失的数据字段显示为“未知”，其他可用信息仍会显示。Open-Meteo 的逐日天气描述表示当天最严重的天气现象，不代表这种天气会持续一整天；和风的逐日描述按白天/夜间分段；彩云的逐日描述是当天主导现象，同样不代表全天持续。

### 丝滑技巧

| 技巧 | 触发 | 说明 |
|---|---|---|
| 颜色识别 | 输入 `#fff`、`rgb(...)`、`hsl(...)` | 结果区出现色块项，`Enter` 复制 HEX；右键可复制 HEX/RGB/HSL 或直接贴为便签 |
| AI 模式内提升对话 | AI 模式中再按 `Alt+Q` | 把主窗内的临时对话导出为持久对话并打开对话窗口 |
| AI 听写防误发 | AI 模式中长按 `Alt+Space` 说话 | 识别终稿只填入输入框**不自动发送**，确认后再 `Enter` |
| 修饰键保护 | 主窗内按 `Alt` / `F1`-`F12` | 不会激活系统菜单栏或冻结窗口，可放心按住 `Alt` 看键帽提示 |

## 3. 剪贴板历史

进入方式：主窗 `Alt+C`（或输入 `剪贴板` 等关键词）。后台自动记录复制的文本与图片。

| 操作 | 触发 | 说明 |
|---|---|---|
| 过滤 | 直接输入 | 模糊搜索剪贴板历史 |
| 类型筛选 | 顶部「全部/文本/图片」chips，或 `Tab` / `Shift+Tab` 循环切换 | 切换类型时自动清除多选 |
| 复制条目 | 选中单条后 `Ctrl+C`，或右键「复制」 | 文本与图片均支持；单项右键菜单会标注 `Ctrl+C` |
| 上屏 | `Enter` / 双击 / `Alt+数字` | 文本真实粘贴到唤起前窗口的输入框（目标不是输入框时自动降级为复制）；图片复制到剪贴板 |
| 编辑条目 | `Alt+E` 或右键「编辑」 | 打开内容编辑器，改完保存为新历史条目 |
| 删除条目 | `Alt+D`、右键删除菜单、或裸 `Delete`（输入为空时） | 快捷键删除选中项，无选择时删除高亮项；右键可选删除范围 |
| 图片条目右键 | 右键图片项 | 钉图（贴到桌面）、直接进图片编辑器（不覆盖剪贴板） |
| 频率加权 | 每次上屏/复制 | 该条目排序自动提前，越用越好找 |

### 多选与批量（推荐养成习惯）

| 操作 | 触发 | 说明 |
|---|---|---|
| 单选 / 多选 | 单击 / `Ctrl+左键` | 文本与图片可混选；Ctrl 再点取消，普通单击改为单选 |
| 区间选择 | `Shift+左键` | 从上次选择锚点选到当前项，跨已加载页面；`Ctrl+Shift+左键` 追加区间 |
| 全选 | `Ctrl+A`（输入为空时） | 全选当前已加载的全部历史项，包含图片 |
| 批量复制 / 上屏 | 纯文本选择后 `Ctrl+C` / `Enter` | 按选择顺序用换行拼接；组合会自动存为一条新历史 |
| 合并编辑 / 便签 | 纯文本选择后 `Alt+E` / `Alt+S` | 合并编辑保留原件；便签合并成一张 |
| 按类型操作 | 混选后右键已选条目 | 上方先列文本复制 / 上屏 / 编辑 / 便签，再列图片钉图；删除区固定为「仅删除文本 → 仅删除图片 → 删除全部选中」，不受选择先后影响 |
| 批量钉图 | 选中图片后右键“钉图” | 按选择顺序逐张打开，错位摆放；每次最多 16 张，单张失败仍继续处理其余图片 |
| 批量删除 | `Alt+D` / 空查询 `Delete` | 删除全部选中项；没有选择时删除当前高亮历史项；失败项保留并提示 |
| 右键选择 | 右键已选 / 未选条目 | 已选条目保留当前组，未选条目改为单选；空白处保留选择 |
| 取消选择 | `Esc` | 有选择时先清空，再按退出剪贴板模式 |

### 丝滑技巧

- 多选状态跨翻页、跨列表刷新保持；窗口隐藏后自动复位，不会误留。
- 混选时 `Ctrl+C` / `Enter` / `Alt+E` / `Alt+S` 会提示从右键菜单选择类型，避免遗漏图片；单张图片仍可复制。
- 批量复制 / 批量上屏产生的组合历史**同组合只保留最新一条**并自动置顶，反复使用不会越积越多。

## 4. 截图与标注

唤起：主窗 `Alt+A`（空输入时；也可在设置中提升为全局快捷键）。

| 操作 | 触发 | 说明 |
|---|---|---|
| 智能预选 | 悬停窗口 / 控件 | 蓝色虚线框 + 挖洞提亮；单击直接采用该区域（鼠标距窗口边缘 10px 内时，单击采用整个窗口） |
| 自由框选 | 左键拖拽 | 实时显示 `(x, y) w × h` 尺寸标签 |
| 调整选区 | 拖边缘 8 向手柄 / 拖选区内部 | 缩放 / 移动（钳制在显示器内） |
| 工具栏 | 框选后自动出现 | 图形（矩形/椭圆/聚光灯/局部放大）、画笔（铅笔/箭头/荧光笔）、文字（文本/数字标号/水印）、马赛克/高斯模糊、橡皮 |
| 撤销 / 重做 / 重置 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） / `Ctrl+R` | 标注命令级撤销；文本输入时撤销/重做作用于文本 |
| 输出 | 复制 / 保存 / 钉图 / 识别 / 翻译 / 翻译并贴图（见 §5） | 选区内双击确认复制截图（包括 OCR 文字上）；OCR 后可图上翻译、拖动划词复制 |
| 长截图 | 工具栏「长截图」 | 滚动目标窗口逐帧拼接，支持「自动滚动」，完成后进标注模式 |
| 取消 | `Esc` / `✕` / 未框选时右键 | 分层关闭：先关 OCR 面板/子面板/下拉，再退整层 |

| 双击全屏复制 | 未框选时在暗罩上双击 | 直接复制整屏 |

| 像素放大镜 | 拖选阶段自动跟随 | 内嵌提示：`Shift` 切换 HEX/RGB/HSL，`C` 复制颜色 |

| 方向键微调 | 标注模式按方向键 | 选区移动 1 物理像素 |
| 文字落袋 | 文字输入框中按 `Esc` | 有内容时提交保留（不丢弃），再按才退出 |
| 配色提取 | 工具栏「提取配色」 | `Ctrl+左键` 多选色、右键复制单色、生成搭配色；「复制整组」右键可选 CSS 变量格式输出 |
| 长图平移 | 长图/编辑态 `Space+拖` 或中键拖 | 平移超长画布 |
| 点击选区外 | 标注中点选区外 | 退出标注重新框选，不会取消截图 |

## 5. 贴图 Pin

创建：截图工具栏「钉图」、OCR 面板「钉图」、剪贴板图片右键「钉图」。贴图窗口始终置顶、不进任务栏。

| 操作 | 触发 | 说明 |
|---|---|---|
| 移动 | 拖动图片 | 超高长图自动切换专用拖动（顶边可拖出屏幕，长图底部可达） |
| 缩放 | 滚轮（`Ctrl+滚轮` 大步进） | 0.1~8 倍，左上角锚定，短暂显示百分比 |
| 缩小为 mini | **双击** | 缩到最长边 160px 的小窗；再双击还原（滚轮或「重置缩放」也可还原） |
| 右键菜单 | 右键 | 编辑图片 / 识别文字 / 翻译图片 / 保存到剪贴板 / 另存为 / 重置缩放 / 关闭（mini 态只保留后两项） |
| 识别文字 | 右键「识别文字」 | 图上出现可划词复制的文字层，双击选整行 |
| 翻译替换 | 右键「翻译图片」 | 译文原地替换渲染并挂划词层；菜单变「还原原图」（仅本次会话内可还原） |

### 丝滑技巧

| 技巧 | 触发 | 说明 |
|---|---|---|
| Esc 优先级链 | 连按 `Esc` | 关菜单 → 退出 mini → 清划选（**不关贴图**，误按保护）→ 关闭贴图 |
| mini 态滚轮还原 | mini 态滚动滚轮 | 直接恢复正常态 |

## 6. 便签与内容编辑器

### 便签

| 操作 | 触发 | 说明 |
|---|---|---|
| 新建 | `Alt+S`（输入框文本进便签；空输入=空白便签）/ 主窗右键「从搜索文本创建便签」/ 剪贴板条目右键「钉为便签」 | 也可以从便签管理器新建 |
| 编辑 | 点击正文直接输入 | Markdown 实时渲染（`#`、`**`、任务清单等），自动保存，窗口标题跟随首行内容 |
| 置顶 / 颜色 | 标题栏图钉 / 调色板按钮 | 7 色便签 |
| 关闭语义 | `Esc` 或 `✕` | 空便签=直接删除；有内容=保存并移入**回收站**（可恢复） |

| 字号缩放 | **`Ctrl+滚轮`** | 0.7~2.0 倍缩放；`Ctrl+中键` 还原默认 |

### 内容编辑器

`Alt+E` 把当前上下文（剪贴板条目 / 输入框 / 系统划词）打开成独立编辑窗口。

| 操作 | 触发 | 说明 |
|---|---|---|
| 保存 | `Ctrl+S` | 写回来源（便签/文件/剪贴板），只保存不关闭 |
| 双视图 | 顶部「原文 / MD」tab，`←` `→` 切换 | MD 视图实时渲染，带格式工具栏 |
| 连续听写 | 底部麦克风按钮 | 长篇口述分段落文，可暂停/继续 |
| AI 整理 | 听写后「整理本次听写」chip，或选中文字后右键 | 产出候选卡，确认才应用；**应用是单事务替换，一次 `Ctrl+Z` 即可整体撤销** |
| 草稿防丢 | 自动 | 编辑自动落草稿；崩溃/忘存后重开自动提示恢复，冲突时给四选对话框 |
| 更多输出 | 顶部 `⋯` 菜单 | 另存副本、复制全文、创建便签、发送到 AI 对话（只预填不发送）、找回未保存草稿 |
| 分层退出 | `Esc` | 依次关菜单 → 停听写 → 取消候选卡 → 关窗（有未保存改动时三选） |

## 7. AI 对话

唤起：`Alt+Q`（主窗有输入文本时自动带入，仅填充不发送）。

| 操作 | 触发 | 说明 |
|---|---|---|
| 发送 / 换行 | `Enter` / `Shift+Enter` | 流式输出 |
| 停止生成 | 生成中点停止按钮或 `Esc` | 已生成内容保留 |
| 空闲隐藏 | `Esc` | 隐藏窗口（会话保留） |
| 编辑重发 | 悬停用户消息 → 编辑 | 修改后截断后续消息重新发送 |
| 双击重命名 | 双击侧栏会话条目 | 行内改名 |
| 拖拽整理 | 拖会话到分组 / 拖分组到另一分组 | 移动会话 / 交换分组顺序 |
| 临时对话 | 侧栏 ⓘ 按钮 | 不落库，header 可「转为持久」 |
| `/skill` 指令 | 输入框键入 `/skill` | 选择已配置的 Skill |
| 上下文详情 | 悬停输入框右侧容量环 | 上下文明细、记忆健康度、可用工具、MCP 状态 |
| 语音输入 | 对话窗可见时长按 `Alt+Space` | 识别文本进对话输入框 |
| 音频转写 | 输入框左侧音频按钮附件 | AI 自动调用转写工具 |

### 丝滑技巧

- 生成中可以继续打字预输入，但 `Enter` 不发送，先停止再发送。
- 未回答完的历史轮次会折叠为摘要条，点「展开」查看全文。

## 9. 你可能不知道的速览

不看这份清单几乎不可能自己发现的东西：

1. **主窗空白处可以拖动**——没有拖动条，但按住卡片空白区就能移动窗口。
2. **主窗滚轮 = 翻页**——结果多于 9 条时，滚轮整页翻。
3. **输入 `>` 直接敲命令**——回车在终端执行，不用先开终端。
4. **输入 `#fff` 识别颜色**——主窗和剪贴板面板都支持，Enter 复制 HEX。
5. **剪贴板混选** — `Ctrl+左键` 增减选择，`Shift+左键` 选区间；纯文本可直接批量复制 / 上屏，混选用右键按类型操作，图片可批量钉图。
6. **剪贴板裸 `Delete` 就是删除**——不用伸手够 `Alt+D`。
7. **截图快捷键角标按组显示**——按住 `Alt` 显示工具切换提示，按住 `Ctrl` 显示撤销/重做/重置提示。
8. **截图滚轮调一切**——选区内可直接调画笔粗细并预览大小；悬停工具按钮/粗细/滑杆/色相条/预设色滚轮也有对应操作。
9. **截图暗罩上双击 = 复制整屏**。
10. **截图标注中按 `E` 开关 OCR 面板**。
11. **截图选完区文字自动可划选**——后台静默 OCR，`Ctrl+C` 直接复制图上文字。
12. **贴图双击缩小成 mini 小窗**——再双击还原；`Ctrl+滚轮` 大步缩放。
13. **贴图连按 `Esc` 不会误关**——优先级链先清划选，最后才关贴图。
14. **便签 `Ctrl+滚轮` 缩放字号**，`Ctrl+中键` 还原。
15. **AI 对话双击会话名 = 重命名**，拖拽即整理分组。
16. **AI 模式里再按 `Alt+Q` 可把临时对话升级为持久对话**。
17. **欢迎页/设置里可以把每个 Chord 动作提升为全局快捷键**——主窗没打开也能 `Alt+A` 截图。
