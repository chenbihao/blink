## 1. 三分钟上手

| 操作 | 触发 | 说明 |
|---|---|---|
| 唤起 / 隐藏主窗 | `Alt+Space`（轻点） | 键位可在设置中修改 |
| 搜索 | 直接输入 | 模糊匹配 + 拼音首字母 + 全拼（`wx` 微信、`dksz` 打开设置），IME 组字期间不打扰 |
| 选择结果 | `↑` `↓` / 鼠标悬停 | 越过视口边界时逐条平移 |
| 打开结果 | `Enter` / 单击 | 按结果类型启动应用、复制或执行动作 |
| 快速触发 | `Alt+1` ~ `Alt+9` | 直接激活当前页第 N 项（主窗内按住 `Alt` 会显示每项的数字角标） |
| 采纳补全 | `Tab` | 输入 `fy` 出现灰影 `fanyi `，按 `Tab` 采纳，直接开始输入翻译内容 |
| 隐藏窗口 | `Esc` / 点击窗口外任意处 | 失焦自动隐藏（AI 生成中除外） |

主窗打开时**按住 `Alt`**，输入框内（空输入时）或底栏（有输入时）会显示当前可用的 Chord 快捷动作键帽，不需要背：

| 组合 | 作用 |
|---|---|
| `Alt+Q` | AI 对话窗口（主窗有输入文本时，文本自动带入对话输入框） |
| `Alt+A` | 区域截图（仅空输入时） |
| `Alt+C` | 剪贴板历史（空输入显示全部；有输入时当前输入转为过滤词） |
| `Alt+E` | 编辑当前内容（优先级：结果项 > 输入框 > 系统划词 > 空白编辑器） |
| `Alt+S` | 钉为便签（取输入框文本；空输入创建空白便签） |
| `Alt+Space`（按住） | 语音输入，松开出字 |

每个 Chord 动作都可以在设置中改键，并提升为**全局快捷键**（主窗隐藏时也能触发）。自定义组合键支持 Ctrl/Alt/Win（可加 Shift）+ 字母/数字/空格/标点/方向键/翻页导航键/F1–F11，或单独 F1–F11；录制无效时状态行会提示具体原因。

## 2. 主窗口与搜索

| 操作 | 触发 | 说明 |
|---|---|---|
| 翻页 | `PgUp` / `PgDn` | 始终整屏移动，保持高亮的相对位置 |
| 滚轮浏览 | 在主窗口滚动滚轮 | 普通搜索与剪贴板共用，默认逐条滚动；在「设置 → 通用 → 主窗口滚轮行为」可切换整页翻页，立即生效并保留浏览位置与选择 |
| 双槽建议 | `Tab` / `Shift+Tab` | 主建议与次建议各占一键；也可直接点击建议行 |
| 命令模式 | 输入 `>` 开头 | 独占模式，回车在终端执行命令；退格删掉 `>` 退出 |
| 计算器 | 直接输入算式 | 出现 `= 结果` 项，`Enter` 复制结果 |
| 剪贴板召回 | 输入 `剪贴板` / `clip` / `jtb` | 不用 `Alt+C` 也能拉出剪贴板历史 |
| 快捷超链 | `bili` 回车打开 B 站主页；`bili 关键词` 搜索 | 触发词支持 Tab 补全；无参数打开主页，有参数使用搜索地址中的 `{query}`。在「设置 → 搜索引擎 → 快捷超链」填写主页及可选搜索地址；主页留空时自动用搜索网址的站点首页地址。列表按名称 A–Z 排序（中文按拼音），可按名称、触发词或网址筛选，列表较长时在卡片内滚动并显示条数；点「从浏览器导入」可一键导入 Chrome / Edge / Brave 的自定义搜索引擎（先预览勾选，触发词可改，冲突会标注原因）。编辑在独立弹窗内完成，触发词冲突保留草稿并提示。默认 GitHub 支持 `gh` 打开主页、`gh 关键词` 搜索 |
| 浏览器书签 | 输入 `bm`；`bm 关键词` 搜索 | 搜索 Chrome / Edge / Brave 书签（标题/网址/文件夹路径，支持拼音首字母）；`bm` 展示最近添加的书签，Tab 补全后可继续输入关键词。结果显示来源浏览器图标，无法提取时回退书签图标；回车仍用默认浏览器打开。书签只在本机内存索引，触发词、浏览器范围与混排开关在「设置 → 搜索引擎 → 浏览器书签」 |
| 文件搜索 | 输入文件名片段 | 搜索全盘文件。在「设置 → 搜索引擎 → 文件搜索」填一个 Everything 端口（默认 80）：端口上已有你装的服务就直接探测共用；没有也不影响——同卡片可一键安装内置搜索引擎（约 1.8 MB，装完自动启用，端口自动分配）。应用自动选择当前可用的搜索来源，无需手动切换 |
| 新版本提示 | 空白唤起时看建议条；输入 `更新` / `检查更新` / `update` | 每天后台自动检查一次新版本。检测到新版时空白主窗建议条显示「Blink x.y.z 可用」，`Tab` 打开设置关于页查看更新日志并一键更新；点行尾 `×` 关闭，本版本不再提示（发布更新的版本后自动恢复）。托盘菜单「检查更新」随时可看；关于页「更新日志」按钮随时展开最近几个版本的更新内容（含当前版本，不依赖有新版）；「设置 → 关于 → 自动检查更新」可关闭自动检查与提示，手动检查不受影响 |
| 空闲上下文建议 | 复制了 URL / 刚划词后唤起 | 建议条自动给出「打开链接 / 问 AI / 翻译划词」，并标注内容来源 |
| 右键菜单 | 右键任意区域 | 剪切/复制/粘贴/全选、Chord 快捷入口、从搜索文本创建便签、便签管理、设置、退出 |
| 结果项右键 | 右键结果条目 | 打开所在文件夹、复制路径/文件名、打开快捷方式目标、重置该项启动频率记录等 |
| 拖动主窗 | 按住卡片空白区拖动 | 移动主窗位置（没有任何视觉暗示，但空白处真的可以拖） |

### 丝滑技巧

| 技巧 | 触发 | 说明 |
|---|---|---|
| 颜色识别 | 输入 `#fff`、`rgb(...)`、`hsl(...)` | 结果区出现色块项，`Enter` 复制 HEX；右键可复制 HEX/RGB/HSL 或直接贴为便签 |
| 自定义搜索直达 | `bil` → Tab → `bili ` | 与插件共用智能 Tab：Tab 采纳主建议、Shift+Tab 采纳次建议。拼音只用于匹配，例如 `jt` 提示「剪贴板」，Tab 后填入真实中文关键词；完整触发词仍显示轻量 Tab 提示，采纳后继续输入搜索内容，反复刷新不会隐藏补全。搜索地址用 `{query}` 表示查询内容，中文和符号自动编码；`bili` 直接回车打开主页。搜索站与主页不同域时手动配置主页（默认 Bilibili 已配置） |
| 书签全文悬浮 | 书签结果行左侧三分之一悬停 | 完整标题、网址与文件夹路径同面板展示，超长标题不再被列表截断 |
| 书签立即更新 | 「设置 → 搜索引擎 → 浏览器书签 → 立即刷新」 | 启动后自动加载，之后定期跟随浏览器里的书签变化自动更新；修改浏览器范围、启用状态或数量上限也会立即重扫。新增书签后等不及就点「立即刷新」强制重读；扫描中显示进度，完成后显示条数 |
| 实时全盘文件索引 | 「设置 → 托管引擎 → 文件搜索引擎」 | 一张卡片管理内置搜索引擎的安装、启停与卸载。想要真正的全盘实时索引，点「安装服务」并授权一次即可；不装服务也能搜，只是首次建立索引需要一点时间 |
| AI 模式内提升对话 | AI 模式中再按 `Alt+Q` | 把主窗内的临时对话导出为持久对话并打开对话窗口 |
| AI 听写防误发 | AI 模式中长按 `Alt+Space` 说话 | 识别终稿只填入输入框**不自动发送**，确认后再 `Enter` |
| 修饰键保护 | 主窗内按 `Alt` / `F1`-`F12` | 不会激活系统菜单栏或冻结窗口，可放心按住 `Alt` 看键帽提示 |

## 3. 剪贴板历史

悬停条目的**左侧三分之一**即可预览：文本显示完整内容（可滚动，拖选后 `Ctrl+C` 复制），图片显示原图（**滚轮以鼠标位置为中心缩放、放大后按住左键拖动、双击复位**）。文件图片支持 PNG、JPG/JPEG、GIF、WebP，动图会播放动画；普通文件显示完整路径，多文件显示路径列表，丢失或无法预览会注明原因。`Esc` 关闭预览。

预览内右键即该条目的菜单：文本可复制、编辑、钉为便签、删除；图片可复制、钉图、编辑；文件可复制路径列表、删除，单张图片文件还可「存为图片条目」并接续钉图或编辑。右键**单条文本或文件条目**时还会自动识别打开类操作——内容是链接就给「打开链接」，是本地路径就给「打开文件 / 打开所在文件夹」。

进入方式：主窗 `Alt+C`（或输入 `剪贴板` 等关键词）。后台自动记录复制的文本、图片与文件路径（文件只存路径**不保存内容**；网络路径等受限来源同样只存路径）。

| 操作 | 触发 | 说明 |
|---|---|---|
| 过滤 | 直接输入 | 模糊搜索剪贴板历史 |
| 类型筛选 | 顶部「全部/文本/图片/文件」chips，或 `Tab` / `Shift+Tab` 循环切换 | 切换时保留搜索词、清除多选并回到首屏；每次进入默认「全部」 |
| 复制条目 | 单选后 `Ctrl+C`；文本/图片也可右键「复制」 | 支持文本、图片与文件；文件写回剪贴板后，在目标位置手动粘贴 |
| 上屏 | `Enter` / 双击 / `Alt+数字` | 文本真实粘贴到唤起前窗口的输入框（对话窗口、便签等应用自身窗口同样支持；目标不是输入框时自动降级为复制）；图片与文件复制到剪贴板，供手动粘贴 |
| 编辑条目 | `Alt+E` 或右键「编辑」 | 打开内容编辑器，改完保存为新历史条目；编辑已置顶的条目时，置顶随新内容转移（旧内容回落常规排序） |
| 置顶条目 | 右键任意文本/图片/文件条目 | 「置顶 1/6/12/24 小时」四档；置顶期间条目固定排在最前（后置顶的排最前）、行尾显示剩余时间，且不按保留期与数量上限清理；已置顶条目再点同档位即重新计时并回到最前，或取消置顶，到期自动回到常规排序；置顶后停留在剪贴板列表，可继续操作 |
| 删除条目 | `Alt+D`、右键删除菜单、或裸 `Delete`（输入为空时） | 快捷键删除选中项，无选择时删除高亮项；右键可选删除范围 |
| 图片条目右键 | 右键图片项 | 钉图（贴到桌面）、直接进图片编辑器（不覆盖剪贴板） |
| 文件条目 | `Enter` / 双击 / `Alt+数字` / 单选 `Ctrl+C` | 把整条路径列表写回剪贴板（文件格式），随后在目标应用手动 `Ctrl+V` 粘贴；按**复制语义**回贴，历史路径已失效时仍可复制 |
| 文件条目右键 | 右键文件项 | 「复制路径列表」（原始路径每行一个的文本）；单文件 PNG、JPG/JPEG、静态 WebP 可「存为图片条目」「存为图片条目并钉图」或「存为图片条目并编辑」，转存 PNG 并保留原文件条目，不覆盖系统剪贴板；GIF 不提供转存入口 |
| 频率加权 | 每次上屏/复制 | 该条目排序自动提前，越用越好找 |

### 多选与批量（推荐养成习惯）

| 操作 | 触发 | 说明 |
|---|---|---|
| 单选 / 多选 | 单击 / `Ctrl+左键` | 文本与图片可混选；Ctrl 再点取消，普通单击改为单选 |
| 区间选择 | `Shift+左键` | 从上次选择锚点选到当前项，跨已加载页面；`Ctrl+Shift+左键` 追加区间 |
| 全选 | `Ctrl+A`（输入为空时） | 全选当前已加载的全部历史项，包含图片 |
| 批量复制 / 上屏 | 纯文本选择后 `Ctrl+C` / `Enter` | 按选择顺序用换行拼接；组合会自动存为一条新历史 |
| 合并编辑 / 便签 | 纯文本选择后 `Alt+E` / `Alt+S` | 合并编辑保留原件；便签合并成一张 |
| 按类型操作 | 混选后右键已选条目 | 上方先列文本复制 / 上屏 / 编辑 / 便签，再列「复制所选文件路径」，图片钉图随后；删除区固定为「仅删除文本 → 仅删除图片 → 仅删除文件 → 删除全部选中」，不受选择先后影响 |
| 批量钉图 | 选中图片后右键“钉图” | 按选择顺序逐张打开，错位摆放；每次最多 16 张，单张失败仍继续处理其余图片 |
| 批量删除 | `Alt+D` / 空查询 `Delete` | 删除全部选中项；没有选择时删除当前高亮历史项；失败项保留并提示 |
| 右键选择 | 右键已选 / 未选条目 | 已选条目保留当前组，未选条目改为单选；空白处保留选择 |
| 取消选择 | `Esc` | 有选择时先清空，再按退出剪贴板模式 |

### 丝滑技巧

- 多选状态跨翻页、跨列表刷新保持；窗口隐藏后自动复位，不会误留。
- 混选时 `Ctrl+C` / `Enter` / `Alt+E` / `Alt+S` 会提示从右键菜单选择类型，避免遗漏图片；单张图片仍可复制。
- 批量复制 / 批量上屏产生的组合历史**同组合只保留最新一条**并自动置顶，反复使用不会越积越多。
- 纯文件多选 `Ctrl+C` 合并复制路径文本（按选择顺序、自动去重）；混选含文件时不提供跨类型上屏，用右键按类型复制。文件条目出现在「全部」与「文件」页签，可按文件名或路径搜索。
- 分类按历史条目类型：以文本形式复制的路径归「文本」；文件、文件夹及多文件组合归「文件」。作为文件条目记录的 PNG 也归「文件」；用「存为图片条目」生成的图片历史另归「图片」，保留原文件条目。
- 预览对超大图片也直接显示原图；「存为图片条目」一次处理一张，特别大的长图可能提示超出限制——能预览不代表能转存。
- GIF 和动态 WebP 只能预览、不能转存（避免丢掉动画）；JPG 转存时会自动按拍摄方向摆正。
- 文件图片可直接转存后钉图或编辑，无需再切到「图片」分类寻找。转存失败不会继续后续操作；若转存成功但钉图或编辑失败，已保存的图片条目仍保留并显示提示。错误反馈位于窗口底部，可显示在悬浮预览上方。编辑器已有活动会话时会激活现有编辑器。
- 剪贴板历史会自动清理：文本默认保留 180 天、最多 1 万条，图片最多 1000 张，均可在「设置 → 快捷键与 Chord → 剪贴板历史」调整（保留期设为 0 即永久）；置顶条目不受自动清理影响。
- 文件路径历史可在「设置 → 快捷键与 Chord → 剪贴板历史」关闭采集或调整上限；删除文件条目只删历史记录，**绝不删除磁盘上的原文件**。

## 4. 截图与标注

唤起：主窗 `Alt+A`（空输入时；也可在设置中提升为全局快捷键）。

| 操作 | 触发 | 说明 |
|---|---|---|
| 智能预选 | 悬停窗口 / 控件 | 蓝色虚线框 + 挖洞提亮；单击直接采用该区域（鼠标距窗口边缘 10px 内时，单击采用整个窗口） |
| 自由框选 | 左键拖拽 | 实时显示 `(x, y) w × h` 尺寸标签 |
| 调整选区 | 拖边缘 8 向手柄 / 拖选区内部 | 缩放 / 移动（钳制在显示器内） |
| 工具栏 | 框选后自动出现 | 图形（矩形/椭圆/聚光灯/局部放大）、画笔（铅笔/箭头/荧光笔）、文字（文本/数字标号/水印）、马赛克/高斯模糊、橡皮 |

### 思考控制（0.27.15）

输入框右侧的「思考」按钮按**当前模型的真实能力**呈现，四种形态：

| 模型能力 | 控件形态 | 可选操作 |
|---|---|---|
| 已知等级（如 GPT-5.4 / Claude Opus 4.6 / Gemini 3 / DeepSeek V3.2+） | 下拉 | 默认（跟随服务端）/ 关 / 开·默认强度 / 各档位（如 low·high·max） |
| 仅开关（如 Claude Sonnet 4.5 预算型 / Kimi k2.6 / 本地 Ollama） | 开关 | 开（默认强度或预算）/ 关 |
| 思考不可关闭（如 Gemini 2.5 Pro / OpenAI o 系列） | 标签「思考 · 始终开启」 | 如实显示限制，不可交互 |
| 不支持思考参数（如 gpt-4o） | 控件隐藏 | — |

- **「默认」不等于关闭**：选择「默认」时不发送任何思考参数，由服务端决定是否思考；要彻底关闭请显式选「关」。
- **能力来源**：内置已验证模型目录（随 rig 0.45 附带）+ 你在模型设置里的「思考控件显示方式」覆盖（自动/强制下拉/强制开关）。自建网关（vLLM 等）显示「能力未知」下拉——档位原样透传，报错时可按提示改选或改用强制开关。
- **越界档位本地拦截**：已知模型选了目录外的档位会在本地报可读错误，不发出请求；档位仍可经设置页模型「自定义参数」透传任意值。
- **预算型模型**（Claude 预算档 / Gemini 2.5）：开关的「开」使用默认预算（2048，随输出上限自动收紧）；要调预算，在模型设置自定义参数里配置 `thinking.budget_tokens` / `generationConfig.thinkingConfig.thinkingBudget`。
- **键盘操作**：下拉打开后 `↑`/`↓` 移动高亮、`Enter`/`Tab` 采纳、`Esc` 关闭；中文输入法组合中不会误采纳。
- 每轮发送的思考状态会随消息落库，导出 Markdown 时在用户消息上附「[思考] 档位/开/关/默认」注记。

### 丝滑技巧

- 未回答完的历史轮次会折叠为摘要条，点「展开」查看全文。

## 9. 插件使用

### 通用操作

- 在 **设置 → 插件 → 插件中心** 刷新官方目录，点击“安装”或“更新”下载插件；词库等资源在对应插件的“数据包”区域下载。
- 在 **设置 → 插件** 中启用插件并展开配置；在主窗口输入触发词即可调用。翻译默认关闭，需要先启用并配置引擎凭据。
- 普通配置修改后自动保存。天气的“保存地点”只提交当前地点草稿，选好地点后需要点击一次。
- 天气与翻译的凭据分组每次打开默认收起，标题显示“未配置／配置不完整／已配置”；展开可找到申请链接。“已配置”表示字段齐全，能否使用以实际查询为准。含空白时可点击输入框下的“移除空格”。密码字段保存在系统凭据管理器中，留空表示保留原值，点击右侧清除按钮才能删除。
- 查询报错时，悬停错误条目左侧三分之一处可查看全文；右键条目或全文预览，选择“复制错误信息”，方便反馈问题。

### 天气

| 怎么调用 | 作用 |
|---|---|
| `天气` / `weather` | 查询已保存的默认地点 |
| `天气 广州` / `weather Guangzhou` | 临时查询其他地点，不改变默认地点 |
| `天气 辽宁/朝阳` / `天气 广州/天河区` | 补充上级地区，区分同名地点 |

**常用操作**：

- 在天气配置中点击“更换地点”，搜索并选中完整候选，再点击“保存地点”。也可手动填写纬度、经度；取消编辑会放弃地点草稿。
- “天气来源”可选 Open-Meteo（免费、无需密钥）、和风天气或彩云天气；温度单位可单独调整。地点搜索面板里的“搜索来源”只决定用哪家服务查找地点。
- 和风天气：在[和风开放平台](https://console.qweather.com/)申请 API Key，并从控制台复制账号专属的 API Host。Host 填裸域名或 `https://` 根地址即可，无需附加接口路径。
- 彩云天气：在[彩云开放平台](https://platform.caiyunapp.com/)申请 App Key 与 App Secret。App Key 显示为普通文本，可直接编辑或清空；App Secret 按密码字段保存。若查询提示确认地点区域，在“更换地点”中选择“中国大陆”或“中国大陆以外”，再保存地点。
- “允许降级到其他来源”默认关闭；开启后可拖动“降级顺序”，主来源失败时依次尝试已配置来源，结果会标明实际来源。只返回部分天气数据时，会说明缺失项。

**实用技巧**：

- 中文地名搜不到时，试试完整区县名、补充上级地区或使用英文名；也可直接填写坐标。
- 首行显示当前天气（当前天气不可用时显示天气摘要），后续每天一条独立预报，展示日期、星期、天气和最低～最高温；副标题显示降水概率与最大风速。
- 选中首行按 `Enter`，复制完整天气摘要；选中某天的预报按 `Enter`，只复制当天预报；选中末尾的来源声明项按 `Enter`，打开来源与使用说明。
- 预报天数以服务实际返回为准；逐日天气描述概括当天情况，不代表该天气会持续一整天。

### 翻译

| 怎么调用 | 作用 |
|---|---|
| `翻译 hello` / `translate hello` | 将文本翻译为设置中的目标语言 |
| 选中译文结果，按 `Enter` | 复制译文 |

**常用操作**：在翻译配置中选择“默认翻译引擎”和“目标语言”，展开对应凭据组申请并填写密钥。支持阿里、百度、腾讯、有道及 DeepL；如需失败后自动换引擎，开启“允许降级到其他引擎”并拖动调整顺序，默认关闭。

**实用技巧**：目标语言设为“自动检测”可快速中英互译：中文输入翻成英文，其他语言输入翻成中文。程序变量名如 `helloWorld`、`hello_world` 会先拆词，方便查看含义。

### IP 查询

**怎么调用**：主窗口输入 `ip`，查看本机地址，以及国内站和国际站看到的出口 IP；选中地址按 `Enter` 复制。输入 `ip` 后列表会显示 `ip refresh` / `ip local` 两个引导项，`Enter` 直接执行对应查询；输入 `ip r` 会出现灰色影子补全，按 `Tab` 补全为 `ip refresh`（输入 `ip 刷`、`ip 本` 等别名前缀同样可补全）。

**常用操作**：在 **设置 → 插件 → IP** 中选择 IPv4 查询范围；“查询 IPv6”默认关闭，开启后显示各一个有效非临时和临时 IPv6，并独立检测一组 IPv6 出口，IPv4 排在前面；“增强网络信息”默认关闭，开启后额外查询网关、隧道/虚拟网卡和系统代理状态，并显示其他有效 IPv6。可拖动调整检测顺序；主检测站失败后会自动尝试同组备用站，也可关闭降级。国际 IPv4 检测站默认附带归属地信息。

**实用技巧**：输入 `ip local` 只看本机地址、不联网；输入 `ip refresh` 刷新出口，仍需遵守检测站的刷新间隔。向局域网设备提供地址时，选择物理网卡的“本机 IPv4”。连续输入时查询会在停顿约半秒后才发起，中间态不会刷出错误行。

| `查词` / `dict` 不带词直接回车 | 直接打开词典独立窗口（插件触发词的通用行为） |

**常用操作**：首次使用需安装词库——在 **设置 → 插件 → 离线词典 → 数据包** 点击“安装”一键下载（基础词库必备，词源增强包可选，词源包附加词根词缀信息）。数据包显示“在线安装暂不可用”表示官方目录暂时拉取不到（目录尚未发布或网络不可达），可在上方“插件中心”区域点刷新重试；开发版（debug 构建）另有“本地包”按钮可从 zip 手动安装。

**实用技巧**：独立窗口里 `Enter` 立即查询、`Esc` 隐藏窗口，每次重新打开都是全新查询；输入过程中词库未收录会即时给出候选——拼错的词优先给最接近的拼写建议（如 aple 给 apple），点击候选直接查询。双击结果区里的英文单词（英文义项、例句里的生词），词旁会弹出速查小卡显示释义，`Esc` 或点击空白处关闭，小卡上可一键转完整词条。词条详情可一键“复制释义”或“复制原词”。全部查询离线完成、断网可用，不用 AI 生成词义；查不到就是词库没有，不会编造。

## 10. 你可能不知道的速览

不看这份清单几乎不可能自己发现的东西：

1. **主窗空白处可以拖动**——没有拖动条，但按住卡片空白区就能移动窗口。
2. **主窗滚轮统一浏览**——普通搜索与剪贴板默认逐条滚动，通用设置可切为整页；方向键始终逐条，`PgUp/PgDn` 始终整页。
3. **输入 `>` 直接敲命令**——回车在终端执行，不用先开终端。
4. **输入 `#fff` 识别颜色**——主窗和剪贴板面板都支持，Enter 复制 HEX。
5. **剪贴板混选** — `Ctrl+左键` 增减选择，`Shift+左键` 选区间；纯文本可直接批量复制 / 上屏，混选用右键按类型操作，图片可批量钉图。
6. **剪贴板裸 `Delete` 就是删除**——不用伸手够 `Alt+D`。
7. **截图快捷键角标按组显示**——按住 `Alt` 显示工具切换提示，按住 `Ctrl` 显示撤销/重做/重置提示。
8. **截图滚轮调一切**——选区内可直接调画笔粗细并预览大小；悬停工具按钮/粗细/滑杆/色相条/预设色滚轮也有对应操作。
9. **截图暗罩上双击 = 复制整屏**。
10. **截图标注中按 `E` 开关 OCR 面板**。
11. **截图选完区文字自动可划选**——后台静默 OCR，`Ctrl+C` 直接复制图上文字。
12. **贴图双击缩小成 mini 小窗**——再双击还原；`Ctrl+滚轮` 大步缩放。
13. **贴图连按 `Esc` 不会误关**——优先级链先清划选，最后才关贴图。
14. **便签 `Ctrl+滚轮` 缩放字号**，`Ctrl+中键` 还原。
15. **AI 对话双击会话名 = 重命名**，拖拽即整理分组。
16. **AI 模式里再按 `Alt+Q` 可把临时对话升级为持久对话**。
17. **欢迎页/设置里可以把每个 Chord 动作提升为全局快捷键**——主窗没打开也能 `Alt+A` 截图。
18. **输入 `更新` 直接检查新版本**。

## 11. 快捷键总表

### 全局（可在设置中修改）

| 按键 | 作用 |
|---|---|
| `Alt+Space`（轻点） | 唤起 / 隐藏主窗 |
| `Alt+Space`（按住） | 语音输入，松开出字，`Esc` 取消 |
| Chord 全局键（可选开启） | 每个动作可配「跟随触发键」或自定义组合 |

### 主窗口内

| 按键 | 作用 |
|---|---|
| `↑` `↓` | 选择结果（越过视口边界时逐条平移） |
| `Enter` | 打开 / 复制 / 上屏 |
| `Alt+1` ~ `Alt+9` | 快速触发对应位置的结果 |
| `PgUp` / `PgDn` | 整页翻页 |
| 滚轮 | 逐条滚动（通用设置可切换整页翻页） |
| `Tab` / `Shift+Tab` | 采纳主 / 次建议 |
| `Esc` | 退出模式 / 清空多选 / 隐藏窗口 |
| `Alt+Q` `Alt+A` `Alt+C` `Alt+E` `Alt+S` | Chord 快捷动作 |
| 按住 `Alt` | 显示 Chord 键帽与结果数字角标 |
| `>` 开头 | 命令模式（回车终端执行） |

### 剪贴板面板内

| 按键 | 作用 |
|---|---|
| `Ctrl+左键` | 多选条目 |
| `Shift+左键` / `Ctrl+Shift+左键` | 区间选择 / 追加区间 |
| `Ctrl+A` | 全选已加载历史项（输入为空时） |
| `Ctrl+C` | 纯文本批量复制；单图片复制；混选用右键按类型操作 |
| `Enter` | 文本上屏 / 单图片复制；纯文本多选时批量上屏 |
| `Tab` / `Shift+Tab` | 循环类型筛选 |
| `Alt+E` / `Alt+S` | 纯文本选择编辑 / 钉便签（多项合并） |
| `Alt+D` / `Delete` | 删除选择，无选择时删当前项；Delete 仅限空查询 |

### 截图标注内

| 按键 | 作用 |
|---|---|
| `Alt+1` ~ `Alt+5` | 切换工具组（重复按循环组内工具） |
| 按住 `Alt` | 显示快捷键角标 |
| `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） / `Ctrl+R` | 撤销 / 重做 / 重置标注 |
| `E` | 开关 OCR 面板 |
| `Shift`（拖选/画图中） | 正方形 / 等比约束 |
| 方向键 | 选区 1px 微调（取色器内精调采样点） |
| `C` / `Shift`（放大镜可见时） | 复制颜色 / 切换色值格式 |
| 双击选区 / 双击暗罩 | 复制选区 / 复制整屏 |
| `Esc` | 分层退出（面板 → 子面板 → 取消截图） |

### 贴图 / 便签 / 编辑器 / 对话窗内

| 按键 | 作用 |
|---|---|
| 滚轮 / `Ctrl+滚轮` | 贴图缩放 / 大步缩放；便签字号缩放 |
| 双击 | 贴图 mini 切换；对话会话重命名 |
| `Esc` | 贴图优先级链；便签关闭（入回收站）；编辑器分层退出；对话窗停止生成 / 隐藏 |
| `Ctrl+S` | 编辑器保存到来源 |
| `Enter` / `Shift+Enter` | 对话发送 / 换行 |
