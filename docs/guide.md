## 1. 三分钟上手

| 操作 | 触发 | 说明 |
|---|---|---|
| 唤起 / 隐藏主窗 | `Alt+Space`（轻点） | 键位可在设置中修改 |
| 搜索 | 直接输入 | 模糊匹配 + 拼音首字母 + 全拼（`wx` 微信、`dksz` 打开设置），IME 组字期间不打扰 |
| 选择结果 | `↑` `↓` / 鼠标悬停 | 越过视口边界时逐条平移 |
| 打开结果 | `Enter` / 单击 | 按结果类型启动应用、复制或执行动作 |
| 快速触发 | `Alt+1` ~ `Alt+9` | 直接激活当前页第 N 项（主窗内按住 `Alt` 会显示每项的数字角标） |
| 采纳补全 | `Tab` | 输入 `fy` 出现灰影 `fanyi `，按 `Tab` 采纳，直接开始输入翻译内容 |
| 隐藏窗口 | `Esc` / 点击窗口外任意处 | 失焦自动隐藏（AI 生成中除外） |

主窗打开时**按住 `Alt`**，输入框内（空输入时）或底栏（有输入时）会显示当前可用的 Chord 快捷动作键帽，不需要背：

| 组合 | 作用 |
|---|---|
| `Alt+Q` | AI 对话窗口（主窗有输入文本时，文本自动带入对话输入框） |
| `Alt+A` | 区域截图（仅空输入时） |
| `Alt+C` | 剪贴板历史（空输入显示全部；有输入时当前输入转为过滤词） |
| `Alt+E` | 编辑当前内容（优先级：结果项 > 输入框 > 系统划词 > 空白编辑器） |
| `Alt+S` | 钉为便签（取输入框文本；空输入创建空白便签） |
| `Alt+Space`（按住） | 语音输入，松开出字 |

在「设置 → Chord 交互」中改键或开启**全局快捷键**，主窗隐藏时也能直接截图、打开对话或创建便签。

## 2. 主窗口与搜索

| 操作 | 触发 | 说明 |
|---|---|---|
| 翻页 / 滚动 | `PgUp` / `PgDn`；滚轮 | 滚轮默认逐条浏览，可在「设置 → 通用」改为整页翻页 |
| 主次建议 | `Tab` / `Shift+Tab` | 补全关键词或执行建议条里的上下文动作 |
| 命令模式 | 输入 `>` 后输入命令 | 回车在终端执行 |
| 计算器 | 直接输入算式 | `Enter` 复制结果 |
| 快捷超链 | `bili` / `bili 关键词`；`gh` / `gh 关键词` | 空参打开主页，带词搜索；在「设置 → 搜索引擎 → 快捷超链」新增或从浏览器导入 |
| 浏览器书签 | `bm` / `bm 关键词` | 浏览最近书签或按标题、网址、文件夹搜索 Chrome / Edge / Brave 书签 |
| 文件搜索 | 输入文件名片段 | 在「设置 → 托管引擎」一键安装内置文件搜索引擎，也可使用已有 Everything 服务 |
| 检查更新 | 输入 `更新` / `update`，或托盘菜单 | 打开关于页查看并安装更新 |
| 上下文建议 | 复制链接或划词后唤起 | 建议条提供打开链接、问 AI、翻译等操作 |
| 右键菜单 | 右键主窗 / 结果条目 | 打开所在文件夹、复制路径、创建便签、打开设置等 |
| 拖动主窗 | 按住卡片空白区拖动 | 移动主窗位置 |

### 丝滑技巧

- 输入 `#fff`、`rgb(...)` 或 `hsl(...)` 识别颜色，`Enter` 复制 HEX；右键可换格式或贴为便签。
- 输入 `bil` 后按 `Tab` 补成 `bili `，再输入搜索词；自定义搜索网址用 `{query}` 作为查询占位。
- 悬停书签结果行的左侧三分之一，可查看完整标题、网址与文件夹；新增书签后可在书签设置中点「立即刷新」。
- 在「设置 → 托管引擎 → 文件搜索引擎」点「安装服务」，可启用全盘实时索引。
- 主窗 AI 模式中再按 `Alt+Q`，可把临时对话转入独立对话窗口保存。

### 多台电脑同步设置

在「设置 → 存储 → 配置同步」填写 WebDAV 连接，点击「保存并测试连接」，再点「立即同步」。首次同步选择上传本机或使用远端配置；有冲突时按项选择保留哪一侧。同步包含常用设置、快捷键和提示词库，密钥与个人内容保留在本机。

## 3. 剪贴板历史

主窗按 `Alt+C`，或输入 `剪贴板` / `clip` / `jtb`。复制过的文本、图片和文件都能在这里找到。

| 操作 | 触发 | 说明 |
|---|---|---|
| 搜索 / 筛选 | 直接输入；顶部类型标签 | 按关键词搜索；`Tab` / `Shift+Tab` 循环切换全部、文本、图片、文件 |
| 预览 | 悬停条目左侧三分之一 | 文本可滚动和划选；图片滚轮缩放、拖动平移、双击复位，动图可播放 |
| 复制 | `Ctrl+C` 或右键 | 复制当前条目；文件可回到目标文件夹手动粘贴 |
| 上屏 | `Enter` / 双击 / `Alt+数字` | 文本粘贴到唤起前的输入框；图片与文件复制后手动粘贴 |
| 编辑 / 便签 | `Alt+E` / `Alt+S` | 把文本送入编辑器或创建便签 |
| 置顶 | 右键 → 置顶 1 / 3 / 7 天 | 常用内容固定在前，也可随时取消 |
| 图片操作 | 右键图片 | 钉图、编辑或问 AI |
| 文件操作 | 右键文件 | 复制路径列表、打开文件或所在文件夹；静态图片文件可转存后直接钉图或编辑 |
| 删除 | `Alt+D` / 空输入时 `Delete` | 删除选中项，无选择时删除当前项；删除文件历史不会删除原文件 |

### 多选与批量

| 操作 | 触发 | 说明 |
|---|---|---|
| 多选 | `Ctrl+单击` | 切换单项选择，可混选文本、图片与文件 |
| 区间 / 全选 | `Shift+单击` / `Ctrl+A`（空输入时） | `Ctrl+Shift+单击` 追加区间；全选当前已加载条目 |
| 批量复制 / 上屏 | 纯文本选择后 `Ctrl+C` / `Enter` | 按选择顺序以换行拼接 |
| 合并编辑 / 便签 | 纯文本选择后 `Alt+E` / `Alt+S` | 合并为一份内容继续处理 |
| 混选操作 | 右键已选条目 | 分别处理所选文本、文件与图片，可批量钉图或按类型删除 |
| 取消选择 | `Esc` | 先清空多选，再按退出剪贴板模式 |

### 丝滑技巧

- 右键预览区也能打开该条目的菜单；右键已选条目会保留整组选择。
- 多选可跨翻页保持。纯文件多选按 `Ctrl+C`，可合并复制路径文本。
- 批量复制或上屏形成的组合会存为新历史，同一组合只保留最新一条。
- 历史保留期在「设置 → Chord 交互 → 剪贴板历史」调整；列表中的 `⏎` 只是换行提示，复制仍保留真实换行。

## 4. 截图与 GIF

唤起：主窗 `Alt+A`（空输入时；也可在设置中提升为全局快捷键）。

| 操作 | 触发 | 说明 |
|---|---|---|
| 智能预选 | 悬停窗口 / 控件后单击 | 采用高亮区域；靠近窗口边缘单击可选整个窗口 |
| 自由框选 | 左键拖拽 | 实时显示 `(x, y) w × h` 尺寸标签 |
| 调整选区 | 拖边缘 8 向手柄 / 拖选区内部 | 缩放 / 移动（钳制在显示器内） |
| 工具栏 | 框选后自动出现 | 图形（矩形/椭圆/聚光灯/局部放大）、画笔（铅笔/箭头/荧光笔）、文字（文本/数字标号/水印）、马赛克/高斯模糊、橡皮 |
| 撤销 / 重做 / 重置 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） / `Ctrl+R` | 标注命令级撤销；文本输入时撤销/重做作用于文本 |
| 输出 | 复制 / 保存 / 钉图 / 识别 / 翻译 / 翻译并钉图（见 §5） | 选区内双击确认复制截图（包括 OCR 文字上）；OCR 后可图上翻译、拖动划词复制 |
| 长截图 | 工具栏「长截图」 | 滚动目标窗口逐帧拼接，支持「自动滚动」，完成后进标注模式 |
| 取消 | `Esc` / `✕` / 未框选时右键 | 分层关闭：先关 OCR 面板/子面板/下拉，再退整层 |

### 丝滑技巧

| 技巧 | 触发 | 说明 |
|---|---|---|
| 快捷键角标 | **按住 `Alt` / `Ctrl`** | `Alt` 显示工具切换角标，`Ctrl` 显示撤销/重做/重置的 Z/Y/R 角标 |
| 组内循环 | 重复按 `Alt+1`~`Alt+5` | 同组工具循环切换，并短暂展开下拉显示当前项 |
| 滚轮调一切 | 悬停工具组按钮 / 粗细档 / 强度·字号滑杆 / 色相·透明度条 / 预设色 / 色彩格式上滚轮 | 分别切换工具、调粗细、步进滑杆、调色、切格式 |
| 画布滚轮调粗细 | 选中画笔后在选区内滚轮 | 上滚加粗、下滚变细，光标圈即时显示笔宽 |
| 正方形约束 | 框选/画矩形/椭圆时按住 `Shift` | 等比约束，按/松实时生效 |
| E 键 | 标注中按 `E` | 召唤 / 关闭 OCR 面板 |
| 双击全屏复制 | 未框选时在暗罩上双击 | 直接复制整屏 |
| 右键三分 | 未框选=取消 / 标注中=复制选区 / 划词中=文字菜单 | 同一个右键三种语义 |
| 静默划词 | 选完区后台自动 OCR | 拖动划选文字后 `Ctrl+C` 复制，右键可复制全文；双击仍确认复制截图。识别完成不自动弹面板，需要时按 `E` 打开 |
| 像素放大镜 | 拖选阶段自动跟随 | 内嵌提示：`Shift` 切换 HEX/RGB/HSL，`C` 复制颜色 |
| 吸管取色 | 颜色面板「从截图取色」 | 全屏点击采样，方向键 1px 精调，`Esc` 只退取色不退截图 |
| 方向键微调 | 标注模式按方向键 | 选区移动 1 物理像素 |
| 文字落袋 | 文字输入框中按 `Esc` | 有内容时提交保留（不丢弃），再按才退出 |
| 配色提取 | 工具栏「提取配色」 | `Ctrl+左键` 多选色、右键复制单色、生成搭配色；「复制整组」右键可选 CSS 变量格式输出 |
| 长图平移 | 长图/编辑态 `Space+拖` 或中键拖 | 平移超长画布 |
| 点击选区外 | 标注中点选区外 | 退出标注重新框选，不会取消截图 |

### GIF 录制与编辑

截图框选后点工具栏「录制」，选好帧率、是否显示光标，再点「开始录制」。

| 操作 | 入口 / 快捷键 | 说明 |
|---|---|---|
| 调整录制位置 | 准备时拖动选区，录制时拖动区域抓手 | 把录制范围移到需要的位置 |
| 暂停 / 继续 | 录制控制条 | 暂停时间不会进入成品 |
| 停止 / 取消 | 录制控制条 | 停止后进入编辑器；取消则丢弃本次录制 |
| 预览 | `Space` 播放 / 暂停，`←` `→` 逐帧 | 查看效果并定位要编辑的帧 |
| 修剪 / 删帧 | 「设为起点」「设为终点」；选帧后 `Delete` | `Shift+单击` 选区间，`Ctrl+单击` 多选 |
| 调节节奏 | 速度、帧时长、循环控件 | 可让重点画面多停留一会儿；工具栏支持撤销、重做 |
| 导出 | 右上角「导出」 | 选择 GIF / MP4、尺寸、质量与保存位置；MP4 为无声、单次播放，循环设置只用于 GIF |
| 安装媒体引擎 | 选择 MP4 后点「管理媒体引擎」 | 安装 FFmpeg 后返回编辑器再次导出，当前编辑会保留；也可在「设置 → 托管引擎 → 媒体引擎」管理 |

小技巧：录制前缩小选区，导出时再选较小尺寸，分享操作演示更轻便。 录制素材保留 72 小时，重要内容请及时导出；已导出的文件不受素材清理影响。

## 5. 贴图 Pin

创建：截图工具栏「钉图」、OCR 面板「钉图」、剪贴板图片右键「钉图」。贴图窗口始终置顶、不进任务栏。

| 操作 | 触发 | 说明 |
|---|---|---|
| 移动 | 拖动图片 | 超高长图自动切换专用拖动（顶边可拖出屏幕，长图底部可达） |
| 缩放 | 滚轮（`Ctrl+滚轮` 大步进） | 调整贴图大小，短暂显示百分比 |
| 缩小为 mini | **双击** | 缩到最长边 160px 的小窗；再双击还原（滚轮或「重置缩放」也可还原） |
| 右键菜单 | 右键 | 编辑图片 / 识别文字 / 翻译图片 / 保存到剪贴板 / 另存为 / 重置缩放 / 关闭（mini 态只保留后两项） |
| 识别文字 | 右键「识别文字」 | 图上出现可划词复制的文字层，双击选整行 |
| 翻译替换 | 右键「翻译图片」 | 译文原地替换渲染并挂划词层；菜单变「还原原图」（仅本次会话内可还原） |

### 丝滑技巧

| 技巧 | 触发 | 说明 |
|---|---|---|
| Esc 优先级链 | 连按 `Esc` | 关菜单 → 退出 mini → 清划选（**不关贴图**，误按保护）→ 关闭贴图 |
| mini 态滚轮还原 | mini 态滚动滚轮 | 直接恢复正常态 |

## 6. 便签与内容编辑器

### 便签

| 操作 | 触发 | 说明 |
|---|---|---|
| 新建 | `Alt+S`（输入框文本进便签；空输入=空白便签）/ 主窗右键「从搜索文本创建便签」/ 剪贴板条目右键「钉为便签」 | 也可以从便签管理器新建 |
| 编辑 | 点击正文直接输入 | Markdown 实时渲染（`#`、`**`、任务清单等），自动保存，窗口标题跟随首行内容 |
| 置顶 / 颜色 | 标题栏图钉 / 调色板按钮 | 7 色便签 |
| 关闭语义 | `Esc` 或 `✕` | 空便签=直接删除；有内容=保存并移入**回收站**（可恢复） |
| 便签管理器 | 右键菜单 / 托盘 | 聚焦、编辑、改色、隐藏、删除；回收站 tab 里恢复 / 彻底删除 / 清空 |
| 字号缩放 | **`Ctrl+滚轮`** | 0.7~2.0 倍缩放；`Ctrl+中键` 还原默认 |

### 内容编辑器

`Alt+E` 把当前上下文（剪贴板条目 / 输入框 / 系统划词）打开成独立编辑窗口。

| 操作 | 触发 | 说明 |
|---|---|---|
| 保存 | `Ctrl+S` | 写回来源（便签/文件/剪贴板），只保存不关闭 |
| 双视图 | 顶部「原文 / MD」tab，`←` `→` 切换 | MD 视图实时渲染，带格式工具栏 |
| 连续听写 | 底部麦克风按钮 | 长篇口述分段落文，可暂停/继续 |
| AI 整理 | 「整理本次听写」或选中文字后右键 | 选择整理、精简、互译等预设；确认后应用，一次 `Ctrl+Z` 撤销 |
| 草稿恢复 | 重开编辑器时提示，或顶部 `⋯` 菜单 | 找回未保存内容 |
| 更多输出 | 顶部 `⋯` 菜单 | 另存副本、复制全文、创建便签、发送到 AI 对话（只预填不发送）、找回未保存草稿 |
| 分层退出 | `Esc` | 依次关菜单 → 停听写 → 取消候选卡 → 关窗（有未保存改动时三选） |

## 7. AI 对话

主窗按 `Alt+Q` 打开对话，输入框已有文字会一并带入，确认后再发送。

| 操作 | 入口 / 快捷键 | 说明 |
|---|---|---|
| 发送 / 换行 | `Enter` / `Shift+Enter` | 生成中按 `Esc` 或点停止按钮；空闲时 `Esc` 隐藏窗口 |
| 切换模型 | 输入框旁模型按钮，或 `/model` | 选择当前对话使用的模型 |
| 添加附件 | 附件按钮，或输入框开头键入 `@` | 选择文件、音频、最近复制的文件/图片或当前会话引用 |
| 图片提问 | 粘贴或拖入图片；截图或剪贴板图片的「问 AI」 | 使用支持图片的模型，输入问题后发送 |
| 常用提示词 | 提示词按钮，或 `/prompt` | 插入到输入框，补充内容后发送 |
| 编辑重发 | 悬停用户消息 → 编辑 | 修改问题并重新生成 |
| 整理会话 | 双击名称；拖会话到分组 | 重命名、移动会话，也可拖动分组排序 |
| 临时对话 | 侧栏 ⓘ 按钮 | 需要保留时在标题栏转为持久对话 |
| 上下文详情 | 悬停输入框右侧容量环 | 查看上下文占用、可用工具与 MCP 状态 |
| 语音输入 | 长按 `Alt+Space` | 识别文本填入对话输入框 |

### `/` 命令与提示词

在输入框开头键入 `/` 打开命令面板，`↑` / `↓` 选择，`Enter` / `Tab` 采纳，`Esc` 关闭面板。

| 命令 | 作用 |
|---|---|
| `/new` | 新建对话 |
| `/model` | 切换模型 |
| `/prompt` | 插入常用提示词 |
| `/skill` | 选择 Skill |
| `/tools` / `/mcp` | 查看可用工具与 MCP 连接 |
| `/compact` | 压缩当前对话上下文 |

在「设置 → AI 对话设置 → 提示词库」管理常用指令。对话提示词从 `/prompt` 插入，编辑器提示词会出现在 AI 整理预设中。

### 丝滑技巧

- 「思考」按钮可选开关或强度，按当前模型显示；「默认」跟随服务端。
- 生成中可以继续打字预输入，停止生成后再发送。
- 剪贴板文本右键「发送到 AI 聊天」，图片右键「问 AI（图片）」，可直接带入内容。
- 未回答完的历史轮次会折叠为摘要条，点「展开」查看全文。

## 9. 插件中心与常用插件

### 插件中心

在「设置 → 插件 → 插件中心」浏览官方插件。

| 操作 | 入口 | 说明 |
|---|---|---|
| 安装 / 更新 | 插件中心的对应按钮 | 下载安装；离线词典安装启用后会自动准备词库 |
| 启用 / 配置 | 已安装插件卡片 | 开启插件、调整选项或填写密钥 |
| 调用插件 | 主窗输入触发词 | 支持 `Tab` 补全；翻译、词典不带参数回车可打开独立窗口 |
| 打开窗口 | 插件卡片「打开页面」 | 适合连续翻译、查词 |
| 卸载 / 恢复 | 插件卡片的安装行 | 可保留或清除数据；随包插件的更新版可恢复为随包版 |

普通选项自动保存，地点等有「保存」按钮的表单需手动提交；密码框留空会保留已有密钥。

### 天气

| 输入 / 操作 | 作用 |
|---|---|
| `天气` / `weather` | 查询默认地点 |
| `天气 广州` / `weather Guangzhou` | 临时查其他地点 |
| `天气 辽宁/朝阳` | 补上级地区，区分重名地点 |
| 选中结果后 `Enter` | 首行复制完整摘要，逐日条目复制当天预报 |

在天气配置中点「更换地点」，搜索并选择地点后「保存地点」。可选免密钥的 Open-Meteo，或配置和风、彩云；需要自动换源时开启降级并拖动排序。

### 翻译

| 输入 / 操作 | 作用 |
|---|---|
| `翻译 hello` / `translate hello` | 主窗快译，选中结果 `Enter` 复制 |
| `翻译` / `translate` 后回车 | 打开独立翻译窗口 |
| `翻译 hello -> ja` | 本次指定译成日文 |
| 翻译配置 | 设置默认引擎、目标语言与引擎密钥 |

默认中英互换：中文译成英文，其他语言译成中文。窗口内可临时改方向与引擎；变量名如 `helloWorld`、`hello_world` 会先拆词再译。

### IP 查询

| 输入 | 作用 |
|---|---|
| `ip` | 查看本机地址及国内、国际出口 IP；`Enter` 复制 |
| `ip local` | 只看本机地址 |
| `ip refresh` | 刷新出口查询 |

输入 `ip r` 后按 `Tab` 补成 `ip refresh`。向局域网设备提供地址时，选择物理网卡的「本机 IPv4」；IPv6 和增强网络信息在插件配置中开启。

### 离线词典

| 输入 / 操作 | 作用 |
|---|---|
| `查词 hello` / `dict hello` | 查释义、音标、词形和短语 |
| `查词 苹果` | 中文反查英文 |
| `查词` / `dict` 后回车 | 打开独立词典窗口，`Enter` 查询，`Esc` 隐藏 |
| 双击结果中的英文单词 | 词旁弹出速查卡，可继续打开完整词条 |

输入拼错时可点击相近候选继续查；详情页可复制释义或原词。词库准备完成后可断网使用，准备进度和重建入口在插件的「数据包」区域。

## 10. 你可能不知道的速览

1. **主窗空白处可以拖动**，不用找标题栏。
2. **剪贴板可以混选**：`Ctrl+单击` 增减选择，右键可按类型批量处理。
3. **截图滚轮调一切**：画笔粗细、工具、滑杆和色板都可用滚轮调整；按住 `Alt` / `Ctrl` 查看快捷键角标。
4. **截图后直接划词**：拖选图上的文字，`Ctrl+C` 复制；`E` 打开 OCR 面板。
5. **贴图双击变 mini**，再双击还原；便签 `Ctrl+滚轮` 调字号。
6. **GIF 重点帧可以延长停留**，演示关键步骤时不用重新录一遍。
7. **词典结果里的生词可以双击查**，词旁弹出速查卡。
8. **`/prompt` 插入常用指令，`@` 找最近复制的附件**，确认后再发送。
9. **主窗 AI 模式再按 `Alt+Q`**，把临时对话转到独立窗口保存。
10. **Chord 动作可设全局快捷键**，主窗隐藏时也能直接截图或开对话。
